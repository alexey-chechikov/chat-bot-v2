# Контекст CoinGlass без Mac — 16.10.2026

Конечная публичная историческая выгрузка Binance USD-M, **не сборщик**, не
CoinGlass API и не результат стратегии. Первичные допущения зафиксированы в
`ASSUMPTIONS.md` до запроса. Ключи, аккаунты, Mac, Claude и ордера не используются.

Получено по **2 592** точки BTCUSDT и ETHUSDT, 15m, за 18.09–15.10.2026 UTC
(конец исключён), 12 GET, 0 пропусков ожидаемой сетки. Исходные JSON сохранены,
их SHA256 и современные времена получения — в `public_oi/manifest.json`.
Четыре синтетических теста проверяют границы времени, пропуски, разные единицы
и отказ при некорректной записи. Данные исторические; это не OOS.

OI количество и денежная оценка сохранены отдельно. Timestamp в официальной
документации — конец периода. Историческая задержка публикации **неизвестна**:
время нынешней загрузки не заменяет время получения историческим трейдером.
Нет интерполяции, заполнения нулём и forward fill. [Официальная спецификация](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data#open-interest-statistics).

`build_context.py` без сети соединяет только фактическое пересечение BTC OI с
ранее подготовленными spot/perp F. Результат `BTCUSDT_price_flow_oi_diagnostic.csv`
содержит **1 729** закрытых 15m-интервалов с 17.09 23:45 до 06.10 00:00 UTC
(конец исключён для начала свечи). Первый бар заканчивается ровно в начале
доступного OI-окна. Точка OI с timestamp
конца бара — **retrospective diagnostic**, не доказанно доступный на close
признак. Lag1/lag4 — только явная чувствительность к сдвигу, не измеренный лаг.
Первый lag1 и первые четыре lag4 неизвестны. Нет сигналов, PnL или выбора
лучших параметров.

Соседний `../strategy_workplan_20261015/public_history/paired_BTCUSDT_spot_perp_15m.csv`
и его исходники доступны в ранее опубликованном воспроизводимом пакете
`docs/STRATEGY_WORK_REPRO_2026-10-15.zip`. `context_manifest.json` содержит SHA
обоих входов/выхода и пределы применимости.

```text
python -B -m unittest -v test_oi
python -B build_context.py
```

`fetch_oi.py` — для однократного получения фиксированного окна до его истечения
у поставщика; после истечения использовать включённый raw архив. Существующий
manifest намеренно не перезаписывается. Воспроизведение CSV из сохранённых raw
возможно в отдельной папке без старого manifest. Новых подписок и API-доступа
CoinGlass для этого не требуется. Матриц карты, исторической интенсивности,
возраста зон, фактических ликвидаций и WEEX исполнения этот архив не содержит.
