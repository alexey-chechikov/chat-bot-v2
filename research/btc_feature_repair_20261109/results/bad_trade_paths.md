# Параметры рисунка

Ретроспективный полный путь закрытий часа для четырёх заранее выбранных пар. Ось X — фактические часы от входа; Y — side×(close−entry)/ATRentry. Каждая линия заканчивается базовым выходом. Треугольник — фактический fill добора по его времени/цене, круг — базовый выход. Вертикали4/12/24ч — точки возможного анализа. Ни один будущий экстремум не используется для входного score.

Покрыты полные позиции; длиннейшая384ч, поэтому ограничение320ч не применено. Все8 путей непрерывны по часу. Суммарный net в легенде относится к позиции с её весом, ногами и комиссиями, без funding; это не величина по осиY. Сравнение не доказывает, что исход можно было уверенно различить на входе.
