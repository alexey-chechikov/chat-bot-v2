1. `BTCUSDT_1m_2017_2024.csv`, `BTCUSDT_funding_full.csv` и точный `w3_series.pkl` первоначального Mac snapshot не найдены. `C:\bot7` frozen minute не совпадает с SHA первоначальной описи. 2. Локальные frozen и reconstructed совпали по **1,040,385 из 1,040,386 общих минут** по OHLCV. Единственное различие — последняя frozen строка **07.05.2026 11:45 UTC**:

   Это согласуется с частичной последней frozen минутой; для целого бара следует использовать завершённый reconstructed, сохранив явный provenance и обе исходные строки. Файлы не изменены.
3. `research/flat_paired_20261103/public_prices/*.zip` — **USD-M futures**, несмотря на имя BTCUSDT-1m. `build_data.py:60` и `data_manifest.json` указывают `/data/futures/um/`. 4. `research/432_multiyear_20261103/data/BTCUSDT_hour.json` и funding там — **Bybit**, не Binance; funding schema `fundingRateTimestamp`. Диапазон 2021-07-01 — 2026-10-31. Не склеивать с Binance spot/funding.
5. H1 spot имеет реальные пропуски. Если replay дополняет пропущенные часы, политика дополнения должна быть фиксированной, отдельно проверенной и одинаковой для old/new; нельзя считать отсутствующую ликвидность наблюдённым нулём.
