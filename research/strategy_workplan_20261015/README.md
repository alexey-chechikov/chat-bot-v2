# Дополнительные исторические данные BTC spot/perpetual — 15.10.2026

Одноразовый офлайн-результат подготовки признаков, не сборщик и не результат стратегии. Фиксированный уже просмотренный исследовательский отрезок: **07.05.2026 00:00 — 06.10.2026 00:00 UTC, конец исключён**.

`public_history/binance_spot_BTCUSDT_15m.csv`: 14 592 полных 15m свечи, OHLCV и taker-buy объёмы. Десять официальных ZIP Binance (пять месячных и пять дневных), каждый проверен по опубликованному `.CHECKSUM`; исходники и checksums сохранены в `archive_cache`. После 01.01.2025 spot-архивы используют микросекунды: нормализованы в миллисекунды без изменения границ свечей. [Описание официальных архивов](https://github.com/binance/binance-public-data).

`public_history/paired_BTCUSDT_spot_perp_15m.csv`: те же 14 592 временных интервала, ноль пропусков. Futures агрегация из ранее загруженных полных 1m, каждая 15m требует ровно 15 последовательных минут. Для каждого рынка отдельно `delta = 2*taker_buy_volume − volume`, `F = delta/volume`. Объёмы в BTC; нулевой объём означает неизвестный F, не придуманный ноль. Это taker-flow из биржевых полей, а не оценка по цвету свечи. [Binance spot klines](https://github.com/binance/binance-spot-api-docs/blob/master/rest-api.md#klinecandlestick-data).

`public_history/manifest.json` содержит SHA256 CSV, исходного futures-файла, скрипта и всех архивов. Проверены сетка UTC, уникальность, длительность, конечность OHLCV, границы цен и taker buy ≤ total. Четыре синтетических теста проверяют единицы timestamps, незакрытый интервал, некорректный buy-volume и пропуск одной futures-минуты.

Воспроизведение из этой папки:

```text
python -m unittest -v test_spot_flow_history
python fetch_spot_flow_history.py
```

Скрипт имеет фиксированные URL и даты; максимум 20 HTTP-запросов при пустом кэше. Он не обращается к аккаунтам, Mac, API-ключам, Claude, ботам или живому WebSocket; заканчивается после сохранения файлов. Нужен прежний `research/expectancy_20261006/public_data/binance_futures_BTCUSDT_1m.csv` с SHA из manifest. При полном кэше все архивы проверяются и читаются без сети; отличный существующий результат не перезаписывается.

**Границы результата:** это не OOS. Исторические timestamps получения данных не восстановлены. OI, фактические ликвидации, матрицы карт, настройка CoinGlass UI и WEEX очередь/исполнение отсюда не следуют. Наличие этих CSV не разрешает датировать старые снимки задним числом, не подтверждает прибыльность spot-flow фильтра и не заменяет prospective-проверку.
