# Daily context archive assumptions — 16 October 2026

- The utility consumes an explicitly supplied JSON and explicitly listed local public evidence. It never fetches websites/APIs, launches collectors, reads account/config/key files or generates trades, forecasts, primary/shadow labels or order permissions.
- `collected_at_ms` and `finished_at_ms` are exact UTC epoch milliseconds supplied by the human-driven collection. Their accuracy is provenance, not independently established by an archive. Finish must be >= collection and no more than 2 seconds ahead of the actual archive clock.
- The day key is derived only from collected time converted using IANA `Europe/Warsaw`, never from UTC date, finished time, URL dates or a requested backfill day. Real runs require the current Warsaw collection day. Archival identity/time/path cannot be supplied in the input. No historical daily backfill is relabeled as a current observation.
- `run_<actualms>` uses the archive machine's actual UTC clock. Collisions are refused, never overwritten or assigned an invented timestamp. A later retry receives a later actual run ID.
- Synthetic input must explicitly say `synthetic:true` and is segregated under `outroot/synthetic/`. Tests use invented fixtures; successful real archive runs are not part of the tests.
- Source timestamps are preserved. Missing as-of is null plus a flag; future as-of, stale as-of and mixed as-of are flags. Default staleness threshold is 24 hours, overridable per source by `stale_after_ms`. As-of age is not provider lag: unknown provider lag remains null/unknown.
- MISSING/FAILED sources retain null/no values, never invented zero. A literal observed zero is valid only for a source reporting values. If every source lacks observed values, overall status is FAILED. Any partial source or quality warning gives PARTIAL; no success is fabricated from partial collection.
- Futures/spot sources remain separate. A group aggregate is never converted to BBO. Forming bars are explicitly flagged when supplied; no closing value is fabricated.
- Typed values require declared type and explicit unit or null. Unknown units remain flagged. Settings and quality flags are recorded as supplied, not optimized or interpreted as actions.
- Evidence paths must be relative `evidence/...` under the input JSON directory. Traversal, absolute paths and symlink escape are refused. Only explicitly listed files are read/copied. Hashes are computed for copied bytes; supplied hashes are compared, with mismatch/missing evidence flagged. This proves byte identity, not truth of the website or correspondence of a typed number to an image.
- Input bytes, report, summary and evidence are staged together and published by directory rename. Existing destinations are refused. An exclusive reservation coordinates concurrent utility instances. The intended host is Windows, where rename refuses an existing destination; no replace operation or mutable latest index is used.
- `order_permission`, `trade_primary_labels_created` and `predictions_created` in the report are always false. Requests to grant trading permissions or attach primary labels are rejected. The archive is a separate daily context record, not the historical journal or any trading-label dataset.
