# Утренняя сводка рынка на маке — для проверки методики (18.10.2026)

Оператор попросил «вывод на день по данным CoinGlass, как изменилась картина со вчера и статистику, чтобы анализ улучшался». Сделано на маке, ежедневно в Telegram — в составе карточки ☀️, 11:00 Варшавы. Код: `services/market_brief/` (`history.py`, `brief.py`), тесты: `tests/services/market_brief/`.

**Данные** — публичные первоисточники панелей CoinGlass. Карта ликвидаций CoinGlass без API недоступна и не используется.
- История, дневная строка UTC:
  - data.binance.vision daily metrics, 5 мин: OI на конец дня, top-trader L/S positions, global L/S, среднее 5-минутных `sum_taker_long_short_vol_ratio`;
  - Binance spot 1d close;
  - сумма фандинга за день.
  
  BTCUSDT и ETHUSDT, 2024-05-15 … вчера, 886 дней. Файл `state/market_brief/features_<SYM>.csv` дописывается каждое утро.
- «Сегодня против вчера» — последние 48 ч Binance REST: `openInterestHist` 1h, `topLongShortPositionRatio` 1h, `takerlongshortRatio` 5m (та же шкала, что история), `fundingRate`, klines 1h. Плюс наши ликвидации Bybit/OKX/Binance за 24 ч и уровень с наибольшей суммой ликвидаций лонгов.

**Условия дня** — 4, заданы до расчёта:
- OI/цена — квадрант, пороги ±0.5% OI и ±0.5% цены;
- фандинг — ниже 20% / между / выше 80% квантиля истории;
- агрессор — по квантилям 20/80%;
- изменение top L/S за сутки — по квантилям 20/80%.

**Статистика:** для дней истории с тем же условием — доля роста на следующие сутки и доля большого хода |ret| > 3% против всех дней.
- «Отличие» — только если доля базы вне интервала Уилсона с **поправкой Бонферрони на 16 сравнений** (z = 2.95) и n ≥ 30.
- Иначе — «как обычный день».

**Журнал:** `state/market_brief/brief_log.jsonl` — условия, цена и вывод каждого дня. На следующее утро печатается «проверка вчерашней сводки»: цена тогда → сейчас и что было сказано.

**Первая сводка, 18.10:** ни одно условие не отличается от обычного дня ни по направлению, ни по размаху. Это согласуется с прежними отказами: OI, фандинг и агрессор не дают эджа (CLAUDE.md, `project_offswitch_nonprice`).
