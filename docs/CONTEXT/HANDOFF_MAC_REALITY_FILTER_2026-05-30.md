## БЛОК 1 — НАХОДКА: paper-метрики системно завышены

Разобрали по диску (не по inventory-докам). Главный пример — `long_multi_divergence`,
наш «лучший эдж»:

| Источник | Что меряет | Результат |
|---|---|---|
| `state/paper_trades.jsonl` | intrabar-touch TP + EXPIRE-в-плюс | **+$4297, WR 98%, 50 сделок** |
| `state/setup_precision_outcomes.jsonl` | реальный исход за окно | **−4.29%, 54 TIMEOUT / 2 SL / 1 TP1 (n=57)** |
| Живой аккаунт (твой, неделя) | реальные филлы | **−$1** |

**Корень:** paper-трейдер фиксирует TP по касанию уровня внутри бара
(intrabar-touch), а не по закрытию. Хуже — 16 EXPIRE-выходов записаны в ПЛЮС
(+$1197). Выход по таймстопу не может быть систематически прибыльным → прямая
ошибка учёта. Целевая функция проекта = бумага, а не реальный филл. Бот
«выигрывает» на симуляторе и стоит у нуля вживую.

Источник истины с этого момента: **`setup_precision_outcomes.jsonl` + живой
аккаунт**, НЕ `paper_trades.jsonl`.
