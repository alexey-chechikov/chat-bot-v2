## 2. ВЕРДИКТЫ 6.1–6.5

**6.1** — см. реестр. «Закрыто» для ADX верно только в смысле «не детектит флет».

**6.2 (К1, SL/ATR-полоса)** — **не тратить цикл.** В наших трендовых ботах стоп — Chandelier k×ATR, то есть SL/ATR константа по построению: К1 там встроен. В H5 стопов нет вообще (B2). Применять К1 не к чему.

**6.3 (мост к TV)** — не поднимать. D2+D3 подтверждают: без Premium и без явной комиссии тестер систематически оптимистичен, а мы уже знаем цену автоподбора (93% зелёных на базе).

**6.4 (что пропустил)** — из роликов ничего. Но пересчёт наших чисел дал три вещи ниже, они важнее всего материала.

**6.5 (флеш-креш)** — **EXIT-FAST на биржу не отправляет ничего.** `services/alt_guard` читает только диск, результат — пинг в TG. Стоп-лоссов в GinArea на OKX нет (`slt=false`). **Но сценарий автора у нас есть в другом месте:** `services/risk_guard` (`enabled`, `allow_close: true`) в `_reduce_positions` закрывает позицию **циклом `api.close_order(bid, oid)` по отдельным ордерам сетки** — N рыночных закрытий подряд. Это ровно форма отказа из интервью. На 10.10.2025 глубина стакана BTC упала >90%, спред BTC-перпов вырос с 0.02 до 26 bp. OKX умеет «Close all» одной reduce-only заявкой — нужно проверить, есть ли аналог в API GinArea.

## 4. ВНЕШНИЙ ПОИСК Ч2

1. **Смена режима без порогов (BOCPD/HMM).** Есть академически (BOCPD, Adams–MacKay 2007; применения к order flow 2023–2025), под гриды — ничего. Замечание: BOCPD — это **обнаружение** уже случившегося сдвига, не прогноз; наша прогнозная линия мертва ×6, а обнаружение дрейфа = как раз живой off-switch. Кандидат с низким априори: BOCPD на собственном инвентаре/дрейфе грида.
2. **Мейкер/ребейт.** Ребейт на OKX — только VIP6+; с 03.06.2026 ELP-ребейт убран для отрицательных уровней. На нашем размере недоступно. Но см. Н3 — мы, похоже, не получаем даже обычного мейкерского тарифа.
3. **Исполнение при каскадном закрытии.** 10.10.2025: $19B ликвидаций, глубина −90%, спред ×1321. Рыночные ордера OKX подчиняются ценовым лимитам и могут не исполниться в тонком стакане. Прямой вход для 6.5/Н1.
4. **Ренж-харвест с хеджем дрейфа.** Ничего нового сверх Avellaneda–Stoikov (2008): перекос котировок по инвентарю. Механически это асимметричная сетка (узкий шаг на сторону, сокращающую инвентарь, широкий — на наращивающую). Наш «множитель шага» 1.05 — симметричная грубая версия, опровергнута (оборот ×4–7.7 меньше). Проверять, только если GinArea допускает асимметрию по сторонам.

## 5б. ВНЕШНИЙ ПОИСК — ВТОРОЙ ЗАХОД

Оператор справедливо назвал первый заход ленивым: восемь запросов, в основном
подтверждение известного. Второй заход — по тому, что может дать механизм.

**Проверено на нашей истории и ОТВЕРГНУТО — эффект экспираций Deribit.** Литература
2025–2026 (в т.ч. Finance Research Letters 2026: внутридневные развороты у
экспираций, сильнее при высокой ATM-гамме) и аналитики говорят: до экспирации
цену «прибивает», после — волатильность расширяется. Проверил на 28 экспирациях
(15.05.2024–29.09.2026) против 2000 наборов случайных недель:

| окно | путь (доход сетки) | эффективность | диапазон |
|---|---|---|---|
| неделя ДО | −6% (перц. 17) | −2% (45) | −10% (14) |
| неделя ПОСЛЕ | +3% (71) | −5% (38) | +8% (82) |
| квартальные ДО | −8% (22) | −21% (22) | −21% (12) |

Направление совпадает с теорией, **значимости нет нигде** (перцентили 12–82).
Внутри дня эффект может быть — там его и нашли; для настроек сетки на недельном
горизонте его нет. Живой пример: после квартальной 25.09 рынок не расширился,
а затих — путь за 98 ч 19.95 при норме ~53 в неделю, эффективность 0.02.

**Не проверено, но впервые у нас — дилерская гамма (GEX) с Deribit.** Публичный
API без ключа. На 29.09 (спот ~83,828): коллы 230k BTC против путов 123k (0.53);
стены коллов 90k/95k/100k, путов 78k/75k/60k; наивная гамма в сумме
+$208 млн на 1% хода, **смена знака около 86,000** — выше дилеры гасят ход,
ниже усиливают. История опционов бесплатно есть на Tardis.dev и
CryptoDataDownload, так что это **проверяемо**: гипотеза «положительная GEX =
режим сетки». Модель наивная (знаки по допущению); Glassnode считает по
реальному потоку тейкеров. Как сигнал не применять до проверки.

**Динамический грид в академии.** arXiv 2506.11921 (Нац. университет Тайваня,
06.2025): классический грид имеет нулевое матожидание, грид с перестройкой
сетки обгоняет и его, и buy&hold на BTC/ETH 2021–2024, ETH лучше BTC. Это
независимое подтверждение того, что делает DYNAMIC GRID в GinArea, и того, что
ETH для сетки лучше BTC. Нового правила оттуда не вынес — полный текст не
прочитал.

**Внутридневная сезонность BTC** (Quantpedia, Concretum 2025): доходность
сосредоточена 21–23 UTC, пик волатильности переехал к открытию США. Для
круглосуточной сетки неприменимо.
