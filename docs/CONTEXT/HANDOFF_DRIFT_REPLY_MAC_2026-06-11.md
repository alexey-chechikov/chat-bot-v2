## Ответы

**Q1 (поток): ДА, формат совпал.** snapshots.csv: ts_utc/position/profit/
current_profit, период 60с. Маппинг ts_utc→ts делаю при сборке DataFrame
(`tracker_reader.read_series(bot_ids, hours=4)`). tsl берём из raw-params бота
(не хардкод −175). Пинги на ПЕРЕХОДАХ вверх: Stage1 🟡 (кулдаун 2ч), Stage2 🟠
(2ч), Stage3 🔴 (повтор каждые 30 мин, пока держится).

**Q2 (авто vs сигнал): Stage2 пока СИГНАЛ, не авто.** Руками менять безопасно —
доказано данными (см. Q4). Но через API — у нас два шрама: 2026-05-17
(set_params c explicit-dataclass дропнул `in`-блок → ВСЕ записи мёртвые, API-spam)
и pause/resume (p=false сбрасывает otcPassed → Failed). Авто-Stage2 только после
теста set_params(gs/tog) на тестовом альт-боте с extra_raw passthrough — могу
сделать TB-альт, но не на живых деньгах сразу. **Stage3 — только сигнал с
кнопкой, авто-закрытия денег не будет** (политика оператора). Пинг Stage3 уже
содержит «закрыть СЕЙЧАС» + total.

**Q3 (калибровка): согласен, копим.** Запущен auto-журнал
`state/alt_guard_bag_journal.jsonl`: worst bag_pct по каждому боту за каждый
день мск (пишется на смене даты). Через 1-2 недели живых прогонов будет
распределение хвоста рейнджеров — порог Stage3 выставим по нему. До тех пор 75%.

**Q4 (step×2 живьём): ДА — доказано данными 10.06** (`scripts/_q4_step_change_check.py`
по экспорту): оператор менял gs/tog 8 раз на живых ботах:
- SOL gs 0.5→0.6 (12:34), →0.7 (14:50), →0.8 (15:04)
- WLD gs 0.5→0.6→0.7→0.8→0.9→1.0 + tog 0.59→0.69→0.89
Во ВСЕХ случаях: status=2 непрерывен, позиция и profit непрерывны. Рестарта/
сброса позиции НЕТ. tsl при сменах не трогался. Stage2 механически валиден.

**Q5 (раскореляция vs BTC): да, но Phase 2.** BTC 1m фид есть
(market_live/market_1m.csv), сравнение хода дешёвое. Но сначала посмотрим
FP/FN текущей лестницы на worst-bag статистике (Q3) — добавлять фичу до
калибровки базовой = тюнить два слоя одновременно. Предлагаю: ты прогоняешь
идею ретро на экспорте 10.06 (BTC 1m у тебя есть в data?) — если идиосинкразия
давала бы Stage-сигнал РАНЬШЕ 16:00 на WLD без ложняков на SOL, втыкаем.
