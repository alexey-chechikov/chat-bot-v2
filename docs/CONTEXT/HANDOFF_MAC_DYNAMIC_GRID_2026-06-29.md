## A. ГЛАВНЫЙ ПРОРЫВ: тумблер «Выход по средней цене» (exit-at-average)

Это решает проблему, на которой мы встали в начале месяца («лонг-мешок симметричного DG не выходит сам,
форвард −4476 → симметричный DG на битке вживую нельзя»). **Один тумблер переворачивает форвард:**

| BTC форвард, max 0.02 | мешок | профит |
|---|---|---|
| Выход-средней **ВЫКЛ** | застрял 1.28 BTC | **−8490** |
| Выход-средней **ВКЛ** | слит в 0 ~16.06 | **+856…+1267** |

**Механика:** грид усредняется вниз (мешок растёт, средняя падает к цене); на отскоке цена встречает
опустившуюся среднюю → закрывает ВЕСЬ мешок флэтом и забирает грайнд. Это естественный выход харвестера —
**дно НЕ угадывает.** Бьёт и Тейк-Профит, и обязательный стоп (которые мы раньше считали единственной защитой мешка).

**2 каваета (критично для твоего сима):**
1. **Транзитная яма.** Эквити ныряет в глубокий минус нереализ ДО флаша: BTC max 0.02 → **−10000** на дне 06–07.06,
   потом выходит в +1185. max 0.03 → −16000. Депо/ликвидация ОБЯЗАНЫ пережить транзит, иначе вынесет на дне.
2. **Работает только на round-trip** (цена вернулась к средней). На сломе БЕЗ возврата мешок зависнет —
   выход-средней НЕ заменяет EXIT-FAST. Стек: выход-средней (штатно на пилах-с-возвратом) + EXIT-FAST 🔴 (на настоящий слом).

## B. ЧЕМПИОНЫ (залочены, зелёные на ОБОИХ окнах)

### BTC Dynamic Grid

```
base 0.4 / дин 0.05 / шаг 0.3 / кол-во 200 / размер 0.005
max 0.02 / mult 1.1 / целевой 0.55 / Выход по средней цене ВКЛ / % режим on

```
→ **база ~+3900 / форвард +1185 (ID 4885002346), транзит-яма −10000.** Поверх — EXIT-FAST 🔴 рубильник.

### ETH Dynamic Grid (= БЕЗОПАСНАЯ нога, яма всего −800)
```
base 0.5 / дин 0.1 / шаг 0.1 / кол-во 200 / размер 0.01
max 0.1 / mult 1.1 / целевой 0.89 / ТП 89 / Выход по средней ВКЛ / % режим on
```
→ **база +1920 (ID 5375339018) / форвард +750 (ID 5018178002), яма −800.** Выход-средней заменил обязательный стоп
(старый ETH-чемпион: +598 форвард / −1500 DD со стопом — устарел, выход-средней даёт И больше профита И вдвое меньше DD).

**ETH мешок в деньгах мелкий** (6 ETH≈$9k vs BTC 1.2≈$84k) → ETH = безопасная нога. На ETH ТП 89 работает (бесплатный рычаг),
на BTC ТП поверх выхода-средней НЕ помогает. На ETH целевой тянет до 0.89, на BTC потолок 0.6 (см. C).

## C. РУЛИ И ЛОВУШКИ (для твоего свипа — НЕ переоткрывай, бери как вход)

1. **Целевой <0.6 = чистый рычаг профита, монотонный на ОБОИХ окнах.** Лестница BTC база:
   0.31→+2426 / 0.39→+2983 / 0.44→+3326 / 0.49→+3613; форвард 0.44→+922 / 0.49→+1072 / 0.55→+1185.
   Объём идёт ПРОТИВ целевого (низкий = чаще закрытия = больше оборот), но размен в пользу профита
   (+1187 профита ценой −272k объёма = копейки против тира $10M/мес). Глубину мешка целевой НЕ трогает.
2. **⚠️ ЦЕЛЕВОЙ 0.6 = ОБРЫВ, не плавный потолок.** Выше ~0.6 выход-средней ЛОМАЕТСЯ (цель так высока, что позиция
   её не достигает → флаш не срабатывает → мешок виснет 1.5 BTC). Форвард: 0.59→+1215 (✓) но **0.67→−9269 / 0.69→−9287** (✗).
   Сдвиг 0.08 переворачивает +1215 в −9269. **ЛОВУШКА БАЗЫ: на базе 0.67=+4529 (ЛУЧШИЙ!) — база ХВАЛИТ обрыв,
   только форвард вскрывает.** Берём 0.55 с отступом. Это та же дисциплина двух движков, что ловила Inside-Bar-завышение.
3. **Макс. размер = ЛИНЕЙНЫЙ множитель мешка.** max 0.01→мешок 0.5 BTC, max 0.05→4.5 BTC и слив ×5 (−6k→−34k).
   С выходом-средней безопасно max 0.02 (яма −10000 vs max 0.03 −16000). НЕ повышать.
4. **⚠️ Шаг 0.2 = ловушка:** тесный шаг заливает грид агрессивнее → мешок ×2 до 2.0 BTC → яма −16000 при ТОМ ЖЕ
   профите. Шаг 0.3 строго лучше.
5. **дин 0.05 > 0.1 на BTC** (доход режет, мешок не уменьшает). На ETH дин 0.1.
6. **Кол-во ордеров НЕ кап клиффа** (проверено трижды на ETH: 500→200 на форварде = нырок всё равно −1500…−1800).
   Клифф = ДРЕЙФ, лечится выходом-средней + EXIT-FAST, не книгой.

## D. ПОРТФЕЛЬНАЯ АРХИТЕКТУРА — и что прорыв в ней МЕНЯЕТ (нужно твоё решение)

**Решение оператора 28.06 (ДО прорыва):** BTC = ДУАЛ направленный (живой каскад SHORT-T1/T2/T3 под
`short_bots_guard`, T2=bot_id 6287583200, TEMA200-гейт + pump_freeze; LONG-D/V5 хедж), симметричный DG на битке
вживую НЕ запускать — «мешок не выходит, −4476». Альты = симметричные DG. SHORT = тактический оверлей, ВКЛ только
по EXIT-FAST 🔴, ВЫКЛ в быке (гейтнутый-всегда-вкл шорт = breakeven за цикл, 5y PF 1.019).

**⚠️ ЧТО ИЗМЕНИЛ ПРОРЫВ (открытый вопрос тебе):** причина «симметричный DG на битке нельзя» была = «мешок не выходит
(−4476)». **Выход-средней ровно этот форвард переворачивает в +1185.** Т.е. главное возражение против симметричного
DG на BTC снято. НО транзитная яма −10000 осталась — а дуал её хеджирует (шорт-нога зарабатывает на том же ходе,
что роет лонг-яму). Так что теперь это НЕ «дуал vs ничего», а **два живых варианта: (a) дуал направленный, (b)
симметричный DG + выход-средней + EXIT-FAST.** Нужен walk-forward обоих на полном цикле, чтобы выбрать (или совместить).

## E. ЧТО СДЕЛАТЬ (твоё — то, что я на Win не могу: настоящий PnL книги + полный цикл)

### Задача 1 [ВЫСШИЙ — про деньги]: walk-forward чемпионов на ПОЛНОМ цикле
- У меня только 2 окна (база + форвард) из скринов оператора. У тебя 2y frozen + грид-сим.
- Прогони BTC-чемпион (раздел B) и ETH-чемпион на полном цикле БитМекс 2y. **Приёмка:** выход-средней держит
  зелёным на каждом году ИЛИ покажи, на каком режиме ломается (нужен ли EXIT-FAST-оверлей именно там).
- **Особое внимание транзит-яме:** замерь max нереализ DD по всему циклу для BTC max 0.02. Если глубже −10000 на
  каком-то крахе — это лимит депо/ликвидации, надо знать число до live.

### Задача 2 [ВЫСШИЙ]: разреши вопрос D — дуал vs симметричный-DG на BTC
- Прогони на полном цикле: (a) дуал (live SHORT-каскад + LONG-хедж под MA100/EXIT-FAST-свитчем) против
  (b) симметричный BTC-DG + выход-средней + EXIT-FAST. Сравни net, max DD, транзит-яму.
- **Приёмка:** какой вариант даёт ≥ net при ≤ DD на полном цикле. Если симметричный-DG+выход теперь не хуже —
  это упрощение книги (одна нога вместо каскада из 3 + гейтов). Если дуал всё ещё хеджирует яму лучше — оставляем дуал,
  но симметричный-DG идёт на альты как есть.

### Задача 3 [СРЕДНИЙ]: семантика «Выход по средней цене» в твоём симе
- Убедись, что твой грид-сим моделирует exit-at-average ТАК ЖЕ, как джижа: закрытие ВСЕГО мешка когда цена
  пересекает средневзвешенную цену входа (флэт по мешку), НЕ по фиксированному уровню. Если сим этого не умеет —
  все мои форвард-числа (+1185 / +750) у тебя не воспроизведутся, и это будет не баг стратегии, а баг сима.
- Связь со стопом по МЕШКУ (`dynamic-auto-sl-semantic`, `current_profit − profit ≤ tsl`) — выход-средней это другой механизм, не путать.

### Задача 4 [СРЕДНИЙ]: перенос на альты
- Перенести связку (выход-средней + потолок-целевого + EXIT-FAST) на SOL/XRP/WLD симметричные DG. ETH уже сделан
  как первый альт. Альты дрейфят жёстче → base оставлять 0.6 (не 0.5), max малый, целевой с тем же отступом от обрыва.
