## СПЕКА (однозначная, воспроизводи точь-в-точь)

**Данные:** BTCUSDT, таймфрейм **4h** (ресэмпл из 1m/15m frozen, 2 года).
**Комиссия:** 0.075% за сторону = **0.15% round-trip** (taker). Заложи обязательно.

**Сигнал (Inside Bar breakout):**
```
inside_bar[i-1] = high[i-1] < high[i-2] AND low[i-1] > low[i-2]
если inside_bar[i-1]:
    если close[i] > high[i-1]:  → LONG (сигнал на баре i)
    если close[i] < low[i-1]:   → SHORT
```
То есть: бар i-1 — внутренний (inside) относительно i-2. На баре i смотрим
пробой границ ВНУТРЕННЕГО бара (i-1) ценой close. Mother bar = i-1 здесь.
Stop-and-reverse: позиция держится до противоположного сигнала ИЛИ до ATR-выхода.

**Выход (winning config): ATR TP=5× / SL=3×**, ATR(14) на 4h.
```
LONG:  TP = entry + 5*ATR,  SL = entry - 3*ATR
SHORT: TP = entry - 5*ATR,  SL = entry + 3*ATR
```
Исполнение: вход по close сигнального бара (в риск-тесте добавлял slip 0.05%).
Выход по касанию TP/SL внутри бара ИЛИ переворот по новому сигналу.
