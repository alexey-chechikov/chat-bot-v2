# Мяч Маку: собрать ВСЁ в один утренний брифинг (Win → Mac, 2026-06-08)

**Оператор:** хочет утром ОДНУ карточку, где всё работает вместе — состояние ботов (твои трекеры)
+ что делать с каждым + альт-кандидаты на запуск + риск портфеля. Я (Win) сделал куски, ты
(продакшн + трекеры + TG) собираешь в пайплайн.

## Компоненты (что есть)

### A. РЕЖИМ BTC (для core/направленных ботов — SHORT-T2 и т.п.) — Win-логика
Живой BTC 4ч → **TEMA200 (красная = водораздел)** + vol-off. Действие по боту:
- цена **ПОД красной** → SHORT-зона: держи шорт; **закрой при реклейме красной +1%**.
- цена **НАД красной** (закреплённо) → LONG-зона.
- vol-off (ATR-z≥2.5) → краш-алерт.
- Пример сегодня: BTC 63.1k, красная 63.9k, шорт держать, закрытие при 64,550.
- Код-референс: fetch klines→TEMA200→action (я гонял, отдам функцию).

### B. АЛЬТ-ГРИД сканер+адаптер — `tools/_alt_grid_scan.py` (готов, на BitMEX-данных)
Утром гоняешь → выдаёт:
- **время-наклон** (US-день 16-20мск = хороший час гриду; утро-UTC = плохой);
- **ранжированные альт-кандидаты** (range × объём × низкий-ER-чоп, флаги опасно/тонкий);
- **готовые Dynamic-Auto MegaHard настройки** под **12% движения** (order_count=12%/step, охват ~12%,
  size из риска, mult≤1.4, target>step, base-offset шире, **TP/SL ±$175** — пресет SL НЕ имел!).
- Сегодня топ: HYPE (баланс), WLD (range, пампнут), SOL (ликв).

### C. ТРЕКЕРЫ БОТОВ — у тебя
Состояние активных: профит (реал/нереал), позиция, дистанция до ликвидации, In/Out Stop, время жизни.

## D. ЧТО СОБРАТЬ (твоя задача) — единый утренний брифинг
Пайплайн утром (cron) → **ОДНА TG-карточка:**
```
☀️ БРИФИНГ <дата> · ⏰ <час, хороший/плохой для запуска>
─ РЫНОК: BTC <px> vs красная <t200> (<режим>) · vol-off <да/нет>
─ АКТИВНЫЕ БОТЫ (из трекеров):
   SHORT-T2: +$X · поз −Y · ликв <далеко/близко> · ДЕЙСТВИЕ: ДЕРЖАТЬ (закрой при 64,550)
   <bot2>: ...
─ РИСК ПОРТФЕЛЯ: суммарная экспозиция, дневной P&L vs лимит, ∑ мешок
─ АЛЬТ-КАНДИДАТЫ на запуск (топ-3 из сканера + настройки)
─ ⚠ алерты: vol-off / бот у SL / бот net-0 (пора закрыть руками)
```

**Поток данных:** cron утром → (1) fetch рынок [A] → (2) `_alt_grid_scan.py` [B] → (3) читаешь трекеры [C]
→ (4) ассемблер собирает карточку → (5) push TG (у тебя tv_webhook есть).

**Что вшиваешь именно ты:** ассемблер + чтение трекеров + TG-доставка. Логику A (BTC-режим) и
B (альт-сканер) бери у меня готовыми (B — файл; A — отдам функцию/встрою в скрипт по запросу).

## РИСК-ГЕЙТЫ (обязательно в брифинг как алерты)
- **SL ±$175/бот** обязателен (особ. альты — пресет SL не имел = OPN-сценарий −$1500-3000).
- **Дневной лимит убытка** 1-2 SL → стоп-день.
- **Isolated margin**, не оставлять агрессивные альт-боты без присмотра НОЧЬЮ (тренд ночью = слив).
- **НЕ полагаться на «5-10 ботов отбалансируют»** — мешки альтов КОРРЕЛИРУЮТ в широком крахе
  (мерил: диверсификация всего +10% в крахе). Защита = SL на каждом, не кросс-боты.
- Закрывать руками на **net-0 / ~$70+** (не ждать полного TP).
