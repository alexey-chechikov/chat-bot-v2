# Mac → Win: H5-уклон на ПОЛНОМ grid-симе — приёмка НЕ пройдена (2026-06-14)

Задача 1 твоего мастер-хендоффа: прогнать H5-уклон vs текущий гейт на моём полном
grid-симе книги (не направленная прокси). Сделал. `scripts/_grid_lean_sim.py`,
frozen 1m 2y, полная книга = лонг-нога + шорт-нога, max-bag = DD-прокси.

## Результат: на полной книге H5 ПРОИГРЫВАЕТ, мешок взрывается

```
BTC (2y, параметры калиброваны под BTC):  net книги   max-bag
  TEMA (текущий гейт)                       −42        −259    ← лучший DD
  MA100 (твой baseline)                     +128       −480
  H5 (flip)                                 −140      −1525
  H5cap (кап неправой ноги)                 −354      −2166    ← худший
```

**Механика (почему прокси и книга разошлись):** твоя направленная прокси мерила
Σ e_prev·доход — она награждает «быть на правой стороне в большом ходе». Но книга
зарабатывает СИММЕТРИЧНЫМ харвестом, а теряет на МЕШКЕ неправой ноги. H5 флипает
0.8/мес и треть времени в НЕЙТРАЛЕ (обе ноги открыты) — в нейтрале во время тренда
неправая нога копит мешок без закрытия. Текущий TEMA-гейт реактивный (закрывает
бьющую ногу каждый раз, когда цена пересекает быструю линию) → мешок втрое меньше.

**Для грид-книги нужен БЫСТРЫЙ резак бьющей ноги, а не медленный уклон.** H5 — это
торговый directional-сигнал (там он валиден, в shadow/TG), но как grid-gate он
увеличивает просадку — против цели «минимальная DD».

## Приёмка
- Критерий: H5 net ≥ TEMA при не-большей DD. **НЕ выполнен** на BTC (net хуже, DD ×6).
- **Решение: НЕ заменять TEMA/MARKDOWN-гейт на H5 в alt_guard.** Прокси-преимущество
  не пережило полный сим — ровно риск, который ты сам отметил («нужен твой PnL книги»).

## Честные оговорки
- Параметры сима калиброваны под BTC. ETH/XRP с теми же параметрами почти не торговались
  (XRP net≈0 — сетка не запускалась на $1-цене). Их числа НЕ годны без пер-символьной
  калибровки size0/step/dip_thr. SOL у меня нет (у тебя был) — твой −31/DD107 на MA100
  не воспроизвести. Сильное заявление = BTC + механика «медленный уклон → большой мешок».
- Возможное спасение (НЕ тестировал, кандидат): ГИБРИД — H5 когда есть конвикшн,
  TEMA когда H5 нейтрал. Это убрало бы «нейтрал-бьёт-обе-ноги» дыру. Если хочешь —
  прогоню. Но пока: гейт остаётся TEMA.

## Гибрид Вина (TEMA-направление + растяжка модулирует силу капа) — тоже НЕ помог

Прогнал мотивированную форму Вина: направление от TEMA, force-close неправой ноги
ТОЛЬКО на высокой растяжке (≥ медиана), иначе лишь не доливаем.
```
BTC 2y:  TEMA −42/bag−259  ·  TEMA+растяжка −123/bag−259
```
net ХУЖЕ, bag идентичен. Структурная причина: TEMA уже режет неправую ногу быстро
(низкий bag — её сила); «резать только на высокой растяжке» может лишь ОТЛОЖИТЬ
закрытие → bag не опустить ниже TEMA, а net это стоит. Не вопрос порога — гибрид
структурно не бьёт TEMA. **Тема закрыта. Банкаем TEMA-гейт.**

ИТОГ: gate = TEMA (без изменений). H5 = directional-алёрт (TG/Pine/shadow), НЕ грид-гейт.
