## СЛОЙ 1 — 🤖 БОТ (робастное ядро, валидировано в grid-$)

### Рекомендация ботам (только из этого)
- **Обе ноги по умолчанию:** ЛОНГ-грид (inverse XBTUSD) + ШОРТ-грид (linear BTCUSDT), независимо.
  В ренже/боковике обе доят пилу → плюс (+155 на 2024-чопе в симе).
- **Price-gate (переключатель):** сторона по красной линии **TEMA200 (4ч)**:
  - `close > TEMA200 × (1 − 0.3%)` → ЛОНГ-нога OPEN; `close < TEMA200 × (1 + 0.3%)` → ШОРТ-нога OPEN.
  - **hold = 2 бара** (условие держится 2×4ч подряд → флип). Причинно (по закрытию бара).
- **⚠️ СЕМАНТИКА = OPEN-STOP, не CUT.** Когда нога не-allowed → **«ПАУЗА новых IN»**, существующие
  IN доживают до target. **НЕ «закрыть ногу».** Force-close теряет деньги (проверено).
- **НЕ использовать стек (жёлтая/красная) для гейта** — только цена vs TEMA200. (Стек — для глаза.)

### Точные числа (бит-в-бит, грид-сим `tools/_grid_sim.py`)
both legs + price-gate (выше), close_mask=None → **2024-чоп +155 / цикл25-26 +100 / крах +9**
(плюс во всех 3 окнах). Параметры сима: step 0.04, target 0.30, min_stop 0.008, size 0.001,
order_mult 1.0 (шаг НЕ растёт), max_orders 600, dip_thr 1.0%, ind_win 30, instop 0.05, restart=True, fee 0.

### vol-off — ДОСОГЛАСОВАТЬ (НЕ авто как есть)
vol-off (ATR%-z ≥ 2.5) cut-both = **net-отрицательный** (2024 +155 → −84: стреляет на не-крах
спайке авг'24). Варианты: (а) **только АЛЕРТ человеку** (не авто), (б) cut только ногу ПРОТИВ
движения, (в) выше порог z. MFI<25-подтверждение помогает циклу (+147) но хрупко. **Решить до live.**
Карточка-СОВЕТНИК может показывать «VOL-OFF: рассмотри пауза/хедж» как алерт.
