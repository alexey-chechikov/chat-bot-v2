## БЛОК 3 — МЕТОДОЛОГИЯ: его vs наша

Шапка `tools/_backtest_detectors_honest.py`:

```
Fee model: IN (limit) maker rebate -0.0125% / OUT (market) taker 0.075% + slippage 0.02%
           -> round-trip 0.165%
Walk-forward: 4 folds x 6 mo. Verdict:
  STABLE   - PF >= 1.5 на 3+/4 folds, N >= 20 per fold
  MARGINAL - PF >= 1.5 на 2/4 folds
  OVERFIT  - иначе
```

Плюс явная **intra-bar SL/TP race** на 1м барах.

| | Его метод | Наш |
|---|---|---|
| Окна | 1 график, «статистика за 2 года» | 4 folds × 6 mo |
| Комиссия | в кадре не упоминается; **TradingView по умолчанию commission = 0** | 0.165%/круг в модели |
| Intrabar SL/TP | не разрешается (TV-тестер) | разыгрывается на 1м |
| Критерий приёмки | «включил фильтры → winrate вырос» | STABLE/MARGINAL/OVERFIT в коде |
| Сайзинг | 100% equity на вход, плечо 4x «чтобы TV не ломался» | размер = главная ось риска (max 0.02 BTC-грид, LONG ≤100k) |

Наши собственные грабли ровно на его процедуре: **93% конфигов зелёные на
базе**; целевой 0.67 = лучший на базе (+4529) и обрыв на форварде; SHORT ETH
mult=1.9 → **−$55k на аптренде**, вскрыт только 4-оконным прогоном; Inside Bar
**+234% → +173%** после строгого детектора (×1.35).
