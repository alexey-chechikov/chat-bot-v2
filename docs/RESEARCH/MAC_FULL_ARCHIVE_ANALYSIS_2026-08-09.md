## 1. Метод

Каждый контакт-лист = 4 слота, каждый слот = один бэктест GinArea со снимком:
график прибыли, график позиции, полная панель параметров, блок статистики
(реализованный / нереализованный / оборот / триггеры / средние цены).

Извлекались поля: `id, pair, strategy, side, entry_pct, step, orders, size,
max_size, mult, target, tp, profit, realized, unrealized, volume, note`.

**Дефекты источника, влияющие на чтение:**
- **Finished vs Stopped.** «Stopped» = прерванный прогон, его итог показывает
  незакрытый мешок на момент обрыва. С завершёнными напрямую не сравним.
- **Дубли** — минимум 7 ID сняты дважды (отфильтрованы через `drop_duplicates`).
- **Мусор** — скриншот ошибки Windows, скриншоты живых ботов оператора
  (HYPE/XRP/LTC/PEPE) вперемешку с бэктестами.

## 9. Окно и метод проверки рекомендаций

### Что проверять

| Гипотеза | Конфиг A (контроль) | Конфиг B (тест) |
|---|---|---|
| Ордера 100→200 | BTC как есть, 100 ордеров | то же + 200 ордеров |
| Кластер-чемпион | — | раздел 6 полностью |
| Целевой ETH | ETH как есть, 0.85 | то же + целевой 0.30 |

### Окна для прогона

**Обязательное — крах:** `10.05.2026 → 28.06.2026`.
Единственное окно в архиве, где 63% прогонов минусуют. Всё, что не проверено
здесь, не проверено вообще.

**Второе — провальные периоды:** `01.10.2025 → 01.01.2026` (47% минусов) и
`05.03.2026 → 04.06.2026` (100% минусов, 11 из 11).
На этих двух окнах в архиве **не выжил ни один конфиг** — если кластер-чемпион
выживет хотя бы на одном, это сильнее всех остальных доводов.

**Третье — база для контроля:** `05.02.2026 → 05.05.2026`.
Нужна только чтобы убедиться, что прогон вообще запустился корректно. Плюс на
базе ничего не доказывает (93% прогонов там в плюсе).

### Критерий приёмки

Кластер-чемпион принимается, если на окне краха:
1. итог не хуже −$5 000 (медиана 200-ордерных DYNAMIC = −$900, худший −$9 288);
2. мешок на конец лучше −$5 000 (порог, за которым доля минусов подскакивает
   с 28% до 77%);
3. оборот сохраняется на уровне $15+ млн (иначе теряется смысл кластера).

Провал любого из трёх = кластер работает только на спокойном рынке, в живую
не выносить.

## 10. Чего этот разбор НЕ доказывает

- **Кластер-чемпион на крахе не проверен.** Все 12 прогонов — окно 10.02–10.05.
  Прогонов этого профиля (INDICATOR / шаг 0.01 / 5000 ордеров) на окне
  10.05–28.06 в архиве нет вообще.
- **Разрезы по шагу и целевому** (раздел 5) смешивают пары, стратегии и окна.
  Годятся как указание направления, не как доказательство.
- **Разрез 100 vs 200 ордеров** — самый чистый в наборе: одно окно, одна
  стратегия, одна пара, один параметр. Опирается на 14 и 45 прогонов.
- **Живой эдж 0.238%** посчитан на $126 613 оборота и включает работу
  харвестера. Для конфигов без харвестера он неприменим.

# ДОПОЛНЕНИЕ 2026-08-13: ПРОСАДКА

В первой редакции просадки не было — извлекались только итог, реализованный,
мешок, оборот и параметры. README архива просил `drawdown shape`, я это
пропустил. Все утверждения о риске выше опирались на долю убыточных и мешок.

Снято дно графика прибыли по **472 прогонам из 774 (61%)** повторным проходом
по контактным листам. Данные: `data/calibration/archive_drawdowns_2026-08-13.csv`
(поля: sheet, slot, id, window, equity_trough, position_extreme, unit, note).

## Что просадка изменила

**Главное: узкий шаг не зарабатывает больше — он рискует больше за те же деньги.**

Самый чистый разрез (одно окно 10.02–08.05, одна пара BTCUSDT, n=92):

| шаг | итог, медиана | дно эквити | прибыль/просадка |
|---|---|---|---|
| ≤0.03 | $2 156 | **−$5 750** | 0.44 |
| >0.03 | $2 064 | **−$1 400** | **1.53** |

Прибыль отличается на 4%, просадка — в 4 раза. Вывод «шаг 0.01 лучше»
из раздела 3 верен по итогу и НЕ верен по риску.

**17% плюсовых прогонов имеют дно глубже трёх итогов** — по прежним данным
они выглядели нормально. Пример: id 4325346764, итог +$1 601, мешок −$734,
дно **−$22 000**.

Мешок предсказывает дно на r=+0.789 — то есть частично оценить просадку
по старым данным было можно, но именно на этих 17% оценка ломается.
