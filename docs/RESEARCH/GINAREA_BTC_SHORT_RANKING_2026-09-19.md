# BTC DYNAMIC SHORT: рейтинг по эффективности + тест масштабирования (Win, 2026-09-19)

**Данные:** `data/calibration/ginarea_runs_btc_short_2026-09-19.csv` — 14 прогонов (BTC Short 11, ETH Auto 3).
Одна строка = один прогон, ID GinArea в колонке `id`. Сделай свои выводы по CSV до раздела «Выводы Win».

## Провенанс и единицы

- Источник: скриншоты оператора, числа перенёс Win вручную.
- `curve_low_approx` — дно кривой прибыли, **снято на глаз с графика** (±10-15%), не из статистики GinArea.
- `position` = поле «Кол-во / Размер», это позиция **на КОНЕЦ окна**, не пик и не средняя за период. ⚠️ Это главное слабое место моего анализа, см. ниже.
- Окно у всех `2025-09-17 → 2026-09-17` (медвежий год, BTC ~115k → ~77k), **кроме 5357902323 — сдвинуто на неделю** (10.09→10.09).
- Пустые `max_size` и `mult` = эскалация выключена.
- ETH-прогоны: Auto, шаг 0.4, размер 0.03, без эскалации, окно 17.09.25→16.09.26.
- Шум прогонов у нас исторически ±5-10%.

## Что проверить в первую очередь (ранжировано по важности)

1. **⚠️ Знаменатель метрики.** Я ранжирую по `profit / position`, где position — позиция на КОНЕЦ окна. Но траектория позиции
   за год разная: у эскалированных конфигов она росла иначе, чем у неэскалированных. Правильнее может быть пиковая или
   средневзвешенная по времени позиция. **Если пересчитать по пику — рейтинг может перевернуться.** Это главное, что надо перепроверить.
2. **Устойчивость разрыва к шуму.** Разрыв между 1-м (11601) и 5-м (10461) местом = 11%, это внутри шума ±5-10%.
   Разрыв «без эскалации против эскалации» = 16% по медианам групп — снаружи. То есть вывод про эскалацию сильный, про шаг — слабый.
3. **Линейность масштабирования.** Проверено один раз (×1.533). Экстраполяция до размера 0.020 — предсказание, не факт.

## Выводы Win (читать после своих)

### Главная метрика: профит на единицу экспозиции, не абсолютный профит

Профит масштабируется размером линейно (тест ниже), поэтому абсолютный профит сравнивать бессмысленно — любой конфиг
«побеждает», если поднять размер. Профит уже включает мешок (профит = реализ + нереализ), поэтому `profit/position` —
полная мера заработка на взятый риск.

### Тест масштабирования размером — подтверждён

шаг 0.8 / цель 1.65 / без эскалации, размер 0.009 → 0.0138 (×1.533):
предсказание **+6564**, факт **+6537**, ошибка **−0.4%**. Профит, объём и дно масштабируются линейно.

**Решающее сравнение при почти равной позиции:** шаг 0.8/размер 0.0138 (поза 0.580) = +6537, 1.36M объёма
против шаг 0.5/размер 0.009 (поза 0.567) = +5932, 1.29M → профит +10.2%, объём +5.3%, эффективность +7.8%.
**Тесить шаг не нужно — это замаскированный и чуть менее эффективный рычаг размера.**

### Инстоп не рычаг

Чистый тест (отличается только инстоп): 0 → +8158, 0.01 → +7950. Разница −2.5% при шуме ±5-10% = незначима.

### Механика мешка (поправка к моему прежнему утверждению)

Ранее я писал, что норму глубины мешка задаёт целевой. **Опровергнуто**: 5248867317 с целью 1.2 без эскалации
закончил на −10.5%, как и цели 1.4/1.65. Настоящая механика: `мешок% = (средняя − цена)/средняя`, а среднюю двигает
в первую очередь **эскалация** — она делает поздние (более высокие для шорта) продажи крупнее и тянет средневзвешенную
вверх к цене. Без эскалации средняя 69238-69453 → −10.2…−10.6% при любом целевом; с эскалацией и целью 1.2
средняя 73457-73789 → −3.8…−4.2%.

### Рекомендация Win

**шаг 0.8 / цель 1.65 / без эскалации / размер под нужную экспозицию.** Проекция на позицию 0.84 (размер 0.020):
ожидание +9452 и объём 1.97M против +8158/1.94M у эскалированного — **+16% профита при той же экспозиции**. Не прогнано.

Размен, который я сознательно принимаю: эскалация даёт среднюю продажу 73615 против 69292 (вход на 6% лучше, мешок вдвое мельче),
но это снимок позиции, а не заработок. 16% эффективности измерены; форвардную экспозицию лечить гейтом, а не эскалацией.

### Что НЕ проверено

**Бычий год.** Всё измерено на одном медвежьем году. Оператор решил бычий год не гонять, а переходить в лонг по факту.
Та же семья конфигов в бычьем году 09.24→08.25 давала −2051 с провалом −34000. Обязательное условие живого запуска —
дневной гейт SMA100-150 (в том бычьем году держал шорт выключенным 100% времени зоны провала, 7-8 переключений в год).
