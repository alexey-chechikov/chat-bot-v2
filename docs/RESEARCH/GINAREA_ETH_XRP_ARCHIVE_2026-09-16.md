Сначала сделай свои выводы по CSV, потом читай раздел «Выводы Win».

## Провенанс и единицы

- Источник: скриншоты оператора, числа перенёс Win вручную. ID прогонов GinArea в колонке `id`.
- `curve_low_approx` — дно кривой прибыли, **снято на глаз с графика** (±10-15%), не из статистики GinArea.
- ETH: OKX `ETH-USDT-SWAP`, USDT_FUTURES (линейный). Профит в USDT, позиция в ETH. `avg_price` = поле «Средняя цена».
- XRP: OKX `XRP-USD-SWAP`, COIN_FUTURES (инверс). **Профит и мешок в XRP**, позиция и объём в USD.
- `trig_filled` = «Кол-во» из блока «Триггеры» на **конец окна** (снимок, не максимум за окно).
- 4553311605 и 6158972066 — почти дубль (разница 0.3%) = шум повторного прогона.
- Общие параметры ETH: base 0.75 / дин 0.1 / Auto / 200 ордеров / мин-макс стоп 0.01-0.1 / выход по средней ON / % режим ON.
- Общие параметры XRP: base 0.5 / дин 0.05 / Short / 150 ордеров / размер 40 / макс 50 / mult 1.02 / мин-макс стоп 0.02-0.23 / выход по средней ON.
