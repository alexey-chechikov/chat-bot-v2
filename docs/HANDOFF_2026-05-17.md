### 1.1 `services/short_bots_guard/` — auto-pause SHORT/LONG GinArea ботов
**Цель**: при cascade-событиях через GinArea API ставит на паузу managed grid-боты, а не просто шлёт TG-нудж.

- `config.py` — read/write `state/short_bots_managed.json` (5 managed bots: 3 SHORT + 2 LONG hedge)
- `control.py` — `pause_bot(bot_id)` / `resume_bot(bot_id)` через GinArea REST (set_params p=false/true)
- `watchdog.py` — раз в минуту чекает `state/cascade_alert_dedup.json`, фаерит auto-pause если fresh trigger (≤5 мин) и не в cooldown (≤6h)
- `resume_conditions.py` — **smart resume** (3 этапа):
  1. Базовая проверка: 1h/4h regime не adverse + нет fresh cascade <20мин + vol regime не HIGH
  2. Если adverse → продлевает паузу на 60мин (max total 12h)
  3. **Reversal override**: если в `state/grid_coordinator_fires.jsonl` свежий exhaustion-fire (🔝 ВЕРХ ИСТОЩАЕТСЯ / 🔻 НИЗ ИСТОЩАЕТСЯ) ≥4/6 score за 45мин — resume, несмотря на adverse regime
- `loop.py` — async loop, async tick 60s

**Triggers и эджи**:
- `cascade_short_5.0` / `cascade_short_2.0`: SHORTs liquidated → 70% pct_up 4h (2024+2026 edge survived) → SHORT grid боты получают unrealized minus → auto-pause
- `cascade_long_5.0` / `cascade_long_2.0`: LONGs liquidated → 65% pct_down 4h (2026 INVERSION эджа) → LONG grid боты в drawdown → auto-pause

### 1.3 `services/manual_levels.py` + TV TG-bridge
**Цель**: хранилище VPVR/key levels уровней с двумя источниками: оператор (TG) + TradingView Premium.

- Schema `state/manual_levels.json`: `{symbol: {poc, vah, val, hvn[], lvn[], session_high, session_low, ttl_hours, source, updated_at}}`
- `parse_levels_text()` — gibкий парсер, понимает 5 форматов:
  - Named: `LEVELS BTCUSD POC=79100 VAH=80500 VAL=78200`
  - Positional 3: `LEVELS BTCUSD 79100 80500 78200` (max→VAH, min→VAL, средний→POC)
  - Positional 5: `LEVELS BTCUSD 79100 80500 78200 81000 78000`
  - Префиксы `LEVELS`/`TV:LEVELS`/`VPVR`/`/levels` — все съедаются
  - `$79,100` запятые/доллар — нормализуется
- TG handlers в `services/telegram_runtime.py`:
  - `/levels` — показать текущие
  - `/levels BTCUSD poc=... vah=... val=...` — обновить вручную
  - `/levels clear BTCUSD` — очистить
  - `handle_text` TV-bridge: любое сообщение начинающееся с `LEVELS`/`TV:LEVELS`/`VPVR` → auto-parse → store

**Pine Script шаблоны**: [TV_PINE_SCRIPTS.md](TV_PINE_SCRIPTS.md) — 4 шаблона (VPVR levels, CVD divergence, Session high/low, HVN/LVN).
