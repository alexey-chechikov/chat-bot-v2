## 3. Что пропущено

1. **Преимущество пробойного входа 432 при переходе к B018 потеряно.** B018 заменил единственный элемент 432 с
   доказательством (момент входа, ранг 0.001 / 0.0005) на вход, который не отличается от случайного (0.067 / 0.079).
2. **«Не режем ли рано сильные движения»** — для 432 нет: в свежей половине удлинение хуже на обеих монетах (§2). Для B018
   режем рано по построению: цель одиночной части ≈1.2R.
3. **Откат / смена режима / истощение.** Проверил одно различение, которое можно было записать заранее: зона v11 на H4 в
   момент выхода 432 → доход следующих 20 H4. BTC: +2.74 п.п. в пользу «зона +1», p 0.02 (на всех барах та же разница
   +0.27); ETH: +0.89, p 0.53 (на всех барах +0.87). Заранее записанный критерий (p ≤ 0.01 на BTC и подтверждение на ETH)
   не пройден — правила «держать, пока зона +1» нет.
4. **LONG и SHORT отдельно** — уже измерено 25.10: зеркальные шорты 432 на портфеле −0.31%/сделку, ранг 0.61; только
   BTC+ETH +0.73%, ранг 0.06, свежая половина −$73. У B018 4 шорта (2 в плюсе) — по ним выводов нет.
5. **H1 и H4** — 432 на H1 слабее (портфель +0.57% против +0.13% у случайного, BTC за 2 года −19%), 15m — нет. В матрице
   Codex у H1 и H1+H4 допущенных вариантов 0, корзины H1+H4 все в минусе.
6. **3–5 ордеров и сетка** — сетка внутри эпизодов 432 не добавляет к самой позиции 432 при той же просадке
   (`research/episode_432_20261102/REPORT.md`: 0.6/1.4 BTC позиция +$727 против сетки +$724). У B018 3 и 5 ордеров почти одинаковы
   (+10.18 / +9.16), а 1 ордер −9.48: решает геометрия цели, а не число частей.
7. **Совместный риск.** 432 — только лонг, живые сетки WEEX — тоже лонг. Совместная кривая не считалась ни разу; без
   неё размер 432 рядом с живыми сетками назначать нельзя.
8. **Другие годы для B018.** Codex прогонял B018 только на мае–октябре 2026. 2020–2025 для правила B018 не просмотрены —
   это самая дешёвая решающая проверка, и её нет.
