## 3. Точная семантика восстановленной зоны

```text
raw_long  = close > TEMA100 and TEMA100 > TEMA200
raw_short = close < TEMA100 and TEMA100 < TEMA200
raw_neutral = neither condition

3 raw_long bars    -> zone = +1
3 raw_short bars   -> zone = -1
3 raw_neutral bars -> zone = 0
otherwise preserve previous zone
```

Красная отдельно не определяет зону v11. Зелёная вообще не входит в формулу зоны; она помогает читать структуру визуально. Поэтому пересечение зелёной и жёлтой не обязано совпадать с переключением фона/зоны.

`zone` не равна полному `mode`: VOL-OFF в исходнике имеет приоритет над зоной. Входные большие треугольники дополнительно зависят от свежего переключения зоны, spread, объёма, RSI и отсутствия VOL-OFF. **Ни таблица ниже, ни метка смены зоны не означают исполненную сделку или воспроизведённый большой треугольник.** Обрезанные настройки VOL-OFF не угадывались, полный расчёт этих маркеров здесь не выполнялся.

Не следует переносить в новую оценку проценты успешности из комментариев Pine («76%», «48%» и т. п.). Наличие такого текста в исходнике не заменяет проверку на отложенной выборке, с остатком и издержками.

### 5.1. До 9 мая: пользовательская идея в основном подтверждается, но есть задержка

**Трактовка пользователя:** цена пробила H1 красную сверху вниз, ретестировала снизу; агрессивные покупки на падающей цене не отменяют шорт; у поддержки и ликвидаций нужно оценивать фиксацию.

**Проверка Codex:** один ранний прокол на закрытии 06.05 19:00 UTC быстро отменяется закрытием 20:00 выше красной. Следующий пробой известен 06.05 23:00 UTC, то есть 07.05 02:00 на шкале UTC+3: close 81,294.4 против красной 81,420.7. Ретест завершается 07.05 08:00 UTC: high 81,671.0, close 81,481.3, красная 81,568.6. Цена поднималась выше ранее известного значения красной и закрылась обратно ниже текущей линии.

Для воспроизводимого описания ретеста использовано правило: после пересечения close вниз, в течение следующих 12 H1 баров, high достигает красной предыдущего закрытого бара, а close остаётся ниже текущей красной; если ранее close возвращается над красной, поиск для того пробоя прекращается. Правило сформулировано после выбора исторического окна, поэтому это не независимая проверка прогностической силы. Окно 12 баров не оптимизировалось; результат описывает форму свечей, а не прибыльный фильтр.

При ретесте H1 зона ещё 0: жёлтая выше красной. H4 SHORT появляется в 20:00 UTC по close 80,112.0, H1 SHORT — в 21:00 по 79,846.0. Между close ретеста и H1 подтверждением цена снизилась на 2.01%; это величина движения, не упущенная гарантированная прибыль. У входа на ретесте и входа по стеку разные триггеры и риск. Их нужно проверять как разные правила.

Голубая H1 EMA200 на ретесте ≈79,395.4, значительно ниже цены. Поэтому жёсткое требование «шорт разрешён только ниже голубой» такой ранний контртрендовый эпизод запретило бы. Это реальный конфликт временных масштабов, а не ошибка цвета. Для нового индикатора нужны отдельные состояния коррекции старшего тренда и полноценного нисходящего тренда.

Но это не доказательство, что любой ранний пробой EMA200 всегда лучше: ложные пробои нужно считать в тех же условиях, а не исключать задним числом.

Дневная SMA100≈66,421 на 19 августа — другая линия и другая частота решения. Её переключение на следующий день после дневного close не следует использовать как единственный защитный стоп интрадей-шорта.

В доступном окне 26 августа — 11 сентября все H4 закрытия остаются над EMA200, но 80.39% ниже красной TEMA200 и 95.10% ниже жёлтой. ### 10.1. Получение публичных свечей

```python
"""One-off public Bybit historical candles. No account access or trading."""
from pathlib import Path
from datetime import datetime, timezone
import hashlib, json, urllib.parse, urllib.request

P=Path(__file__).resolve().parent
OUT=P/'public_data'
OUT.mkdir(exist_ok=True)
def ms(s):
    return int(datetime.fromisoformat(s).replace(tzinfo=timezone.utc).timestamp()*1000)

manifest=[]
if (OUT/'provenance.json').exists():
    manifest=json.loads((OUT/'provenance.json').read_text())
for name, interval, start_s in [('bybit_1h','60','2026-01-01'),('bybit_4h','240','2025-01-01')]:
    path=OUT/(name+'.json')
    if path.exists():
        print(name,'already archived',flush=True)
        continue
    start,end=ms(start_s),ms('2026-09-16')-1
    cursor=end
    rows=[]
    while cursor>=start:
        q=dict(category='linear',symbol='BTCUSDT',interval=interval,start=start,end=cursor,limit=1000)
        url='https://api.bybit.com/v5/market/kline?'+urllib.parse.urlencode(q)
        with urllib.request.urlopen(url,timeout=25) as r:
            raw=r.read()
        data=json.loads(raw)
        if data.get('retCode')!=0:
            raise ValueError(str(data)[:300])
        batch=data['result']['list']
        manifest.append(dict(url=url,retrieved_utc=datetime.now(timezone.utc).isoformat(),rows=len(batch),response_sha256=hashlib.sha256(raw).hexdigest()))
        (OUT/'provenance.json').write_text(json.dumps(manifest,indent=2),encoding='utf-8')
        if not batch:
            break
        rows.extend(batch)
        earliest=min(int(x[0]) for x in batch)
        if earliest>cursor: raise ValueError('Non-advancing page')
        cursor=earliest-1
        print(name,len(rows),flush=True)
        if len(batch)<1000: break
    rows.sort(key=lambda r:int(r[0]))
    assert len({int(r[0]) for r in rows})==len(rows)
    step=int(interval)*60000
    assert [int(r[0]) for r in rows]==list(range(start,end+1,step))
    path.write_text(json.dumps(rows,separators=(',',':')),encoding='utf-8')
    print(name,'complete',len(rows),hashlib.sha256(path.read_bytes()).hexdigest(),flush=True)
```

### 10.2. Расчёт и проверки

```python
"""Closed-bar reconstruction of screenshot MAs, not a trading/grid backtest."""
from pathlib import Path
import hashlib, json
import numpy as np
import pandas as pd

P=Path(__file__).resolve().parent
WINDOWS=[('MAY_6_9','2026-05-06','2026-05-10'),('MAY_10_13','2026-05-10','2026-05-14'),
 ('MAY_12_22','2026-05-12','2026-05-23'),('MAY31_JUN6','2026-05-31','2026-06-07'),
 ('JUN_7_11','2026-06-07','2026-06-12'),('JUN_12_15','2026-06-12','2026-06-16'),
 ('JUN_16_JUL1','2026-06-16','2026-07-02'),('JUL_2_AUG15','2026-07-02','2026-08-16'),
 ('AUG_19_25','2026-08-19','2026-08-26'),('AUG26_SEP11','2026-08-26','2026-09-12')]

def read(tf):
    raw=json.loads((P/'public_data'/f'bybit_{tf}.json').read_text())
    f=pd.DataFrame(raw,columns=['ts','open','high','low','close','volume','turnover']).astype(float)
    f.index=pd.to_datetime(f.pop('ts').astype('int64'),unit='ms',utc=True)
    f.index.name='open_utc'
    return f

def calc(f,tf):
    f=f.copy()
    for n in (50,100,200):
        e1=f.close.ewm(span=n,adjust=False).mean()
        e2=e1.ewm(span=n,adjust=False).mean()
        e3=e2.ewm(span=n,adjust=False).mean()
        f[f'tema{n}']=3*e1-3*e2+e3
        if n==200:f['ema200']=e1
    f['dc_low30']=f.low.shift(1).rolling(30).min()
    f['dc_high30']=f.high.shift(1).rolling(30).max()
    f['raw_zone']=np.select([(f.close>f.tema100)&(f.tema100>f.tema200),
                             (f.close<f.tema100)&(f.tema100<f.tema200)],[1,-1],default=0)
    # v11 preserves the old committed state until THREE consecutive raw states agree.
    zone=0; prev=None; run=0; zones=[]
    for raw in f.raw_zone:
        run=run+1 if raw==prev else 1
        if run>=3:zone=int(raw)
        zones.append(zone); prev=raw
    f['zone']=zones
    f['spread_pct']=(f.tema100-f.tema200).abs()/f.close*100
    f['known_utc']=f.index+pd.Timedelta(tf)
    for left,right,key in [('close','tema200','price_red'),('close','tema100','price_yellow'),
                            ('close','ema200','price_cyan'),('tema50','tema100','green_yellow'),
                            ('tema100','tema200','yellow_red')]:
        d=f[left]-f[right]
        f[key+'_up']=(d>0)&(d.shift(1)<=0)
        f[key+'_down']=(d<0)&(d.shift(1)>=0)
    f['zone_change']=f.zone.ne(f.zone.shift(1))
    # A completed-bar retest observation, not a guaranteed intrabar fill.
    crosses=np.flatnonzero(f.price_red_down.to_numpy())
    retest=np.zeros(len(f),dtype=bool)
    cross_idx=np.full(len(f),-1,dtype=int)
    for c in crosses:
        for j in range(c+1,min(c+13,len(f))):
            if f.close.iloc[j]>=f.tema200.iloc[j]:break
            if f.high.iloc[j]>=f.tema200.iloc[j-1]:
                retest[j]=True;cross_idx[j]=c;break
    f['red_retest_below']=retest
    f['retest_cross_index']=cross_idx
    return f

def window(f,start,end):
    return f[(f.index>=pd.Timestamp(start,tz='UTC'))&(f.index<pd.Timestamp(end,tz='UTC'))]

def summarize(frames):
    rows=[]; events=[]
    for tf,f in frames.items():
        for label,start,end in WINDOWS:
            g=window(f,start,end)
            rows.append(dict(window=label,tf=tf,n=len(g),ret_pct=(g.close.iloc[-1]/g.open.iloc[0]-1)*100,
                below_red_pct=(g.close<g.tema200).mean()*100,below_yellow_pct=(g.close<g.tema100).mean()*100,
                below_cyan_pct=(g.close<g.ema200).mean()*100,zone_short_pct=(g.zone==-1).mean()*100,
                zone_long_pct=(g.zone==1).mean()*100,zone_flat_pct=(g.zone==0).mean()*100,
                zone_changes=int(g.zone_change.sum()),narrow_pct=(g.spread_pct<.6).mean()*100))
        g=window(f,'2026-05-01','2026-09-16')
        keys=[c for c in g if c.endswith('_up') or c.endswith('_down')]+['zone_change','red_retest_below']
        for t,r in g.iterrows():
            for key in keys:
                if not r[key]:continue
                e=dict(tf=tf,open_utc=t.isoformat(),known_utc=r.known_utc.isoformat(),event=key,
                       close=r.close,tema50=r.tema50,tema100=r.tema100,tema200=r.tema200,ema200=r.ema200,zone=int(r.zone))
                if key=='red_retest_below':
                    e['cross_known_utc']=f.iloc[int(r.retest_cross_index)].known_utc.isoformat()
                events.append(e)
    return pd.DataFrame(rows),pd.DataFrame(events)

def verify(frames):
    results=[]
    def ck(name,ok,detail=None):
        results.append(dict(check=name,pass_=bool(ok),detail=detail))
        assert ok,(name,detail)
    for tf,f in frames.items():
        expected=pd.date_range(f.index[0],f.index[-1],freq=tf)
        ck(tf+'_continuous_unique',f.index.equals(expected) and f.index.is_unique,len(f))
        ck(tf+'_ohlc',((f.low<=f[['open','close']].min(axis=1))&(f.high>=f[['open','close']].max(axis=1))&(f.high>=f.low)).all())
        ck(tf+'_available_at_close',(f.known_utc==f.index+pd.Timedelta(tf)).all())
        # Independent explicit recurrence, not pandas ewm.
        src=f.close.to_numpy(); independent={}
        for n in (50,100,200):
            a=2/(n+1); e=np.empty((3,len(src)))
            for k in range(3):
                x=src if k==0 else e[k-1];e[k,0]=x[0]
                for j in range(1,len(src)):e[k,j]=a*x[j]+(1-a)*e[k,j-1]
            independent[n]=3*e[0]-3*e[1]+e[2]
            ck(tf+'_tema_recurrence_'+str(n),np.allclose(independent[n],f[f'tema{n}'],atol=1e-7,rtol=0))
        # Historical features at checkpoints must equal calculation on prefixes.
        for end in ('2026-05-07 13:00','2026-06-07 12:00','2026-08-19 16:00'):
            raw=read(tf);short=raw[raw.index<pd.Timestamp(end,tz='UTC')]; z=calc(short,tf)
            cols=['tema50','tema100','tema200','ema200','zone','dc_low30','dc_high30']
            ck(tf+'_prefix_'+end,np.allclose(z[cols].iloc[-1],f.loc[z.index[-1],cols].astype(float),atol=1e-8,rtol=0))
        # Reinitialize at a later past date; assess residual seed sensitivity on target period.
        seed_start='2026-02-01' if tf=='1h' else '2025-04-01'
        alt=calc(read(tf).loc[seed_start:],tf)
        columns=['tema50','tema100','tema200','ema200']
        diff=(f.loc['2026-05-01':,columns]-alt.loc['2026-05-01':,columns]).abs().max().max()
        ck(tf+'_warmup_sensitivity',diff<.05,{'max_USDT':float(diff),'alternate_start':seed_start})
        ck(tf+'_warmup_zone_identical',(f.zone.loc['2026-05-01':]==alt.zone.loc['2026-05-01':]).all())
    hourly=read('1h').resample('4h').agg({'open':'first','high':'max','low':'min','close':'last','volume':'sum','turnover':'sum'})
    direct=read('4h').loc[hourly.index]
    diff=(direct[['open','high','low','close']]-hourly[['open','high','low','close']]).abs().max().max()
    ck('direct_4h_matches_aggregated_1h',diff<=.11,float(diff))
    # Futures-only Binance comparison is for source sensitivity, not a replacement for Bybit.
    b=json.loads((P.parent/'market_regimes_review_20261102/public_data/btc_1h.json').read_text())
    bs=pd.Series([float(r[4]) for r in b],index=pd.to_datetime([r[0] for r in b],unit='ms',utc=True))
    by=frames['1h'].close.loc[bs.index]
    d=(by/bs-1)*100
    ck('bybit_vs_binance_close_difference_below_0_1pct',d.abs().max()<.1,
       dict(median_abs_pct=float(d.abs().median()),max_abs_pct=float(d.abs().max())))
    return results

def main():
    frames={tf:calc(read(tf),tf) for tf in ('1h','4h')}
    checks=verify(frames)
    stats,events=summarize(frames)
    stats.to_csv(P/'window_stats.csv',index=False)
    events.to_csv(P/'events.csv',index=False)
    for tf,f in frames.items():f.loc['2026-05-01':].to_csv(P/f'features_{tf}.csv')
    (P/'checks.json').write_text(json.dumps(checks,indent=2),encoding='utf-8')
    manifest=[]
    for file in sorted((P/'public_data').glob('*.json')):
        manifest.append(dict(path=str(file.relative_to(P)),sha256=hashlib.sha256(file.read_bytes()).hexdigest(),bytes=file.stat().st_size))
    (P/'manifest.json').write_text(json.dumps(manifest,indent=2),encoding='utf-8')
    print('Checks:',len(checks),'pass; events:',len(events))
    print(stats[['window','tf','below_red_pct','below_yellow_pct','below_cyan_pct','zone_short_pct','zone_changes']].round(2).to_string(index=False))

if __name__=='__main__':main()
```
