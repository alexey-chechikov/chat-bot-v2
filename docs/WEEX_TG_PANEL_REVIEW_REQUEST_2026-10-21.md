# Пульт сеток в Telegram (/panel) и заряженные шорт-сетки SB/SE — на проверку, 21.10.2026

Ветка `alexey/tg-panel` (поверх `2113792`). **Не задеплоено** — торговый код; ждёт «да» оператора на дифф и проверку GPT.

## Запрос оператора и решения

«Кнопки управления ботами: пауза всем ботам, закрыть все позиции, старт отдельного бота, заранее заряженные — нажимаю
настроенного шорт-бота; отдельно увеличить/уменьшить ордер кнопкой, так же для лонговых». Решения оператора 21.10
(вопрос с вариантами): шорт-сетки **ETH и BTC без режима SMA**; «закрыть все» — **только позиции ботов**.

Что известно против (сказано оператору): постоянная шорт-сетка ETH — минус во всех 30 ячейках развёртки; шорт-сетки в
ралли 19–22.08 — мешок ~$16k; держит только потолок позиции. Сторона SHORT BTC у основной сетки BTC передана оператору
(`release_sides`) — SB делит её с его ручными шортами.

## Что сделано

| Часть | Файл | Суть |
|---|---|---|
| Заряженные шорт-сетки | `engine.py` `GRIDS`, `TEMPLATES` | SB: BTCUSDT SHORT 0.6/1.4, 0.0012, 30 ордеров / $3 000, знак `5`; SE: ETHUSDT SHORT 0.6/1.4, 0.040, 30 / $3 000, знак `6`; `regime_sma=0`; по умолчанию `enabled=false`, `dry_run=true` — без файла конфига ничего не делают (цикл не делает ни одного запроса) |
| Закрытие по команде | `engine.py` `tick` | `flatten_request: [LONG/SHORT]` в конфиге → сторона в `closing` → **тот же путь, что закрытие по режиму** (`_flatten_side`: снять вход и тейки, один reduceOnly на объём лотов бота, намерение до отправки, неясный исход — без повтора). | Команды | `loop.py` | `go` (живой + включить + снять закрытие), `close` (выключить + `flatten_request` по сторонам с лотами/входом), `qty+`/`qty-` (≈$50 по цене, кратно шагу объёма, через `set_params` с его пределами), `pauseall` (только живые включённые), `closeall` (только живые с позицией); `start` снимает `flatten_request` |
| Пульт | `panel.py` (новый), `telegram_runtime.py` `/panel` | Одна карточка с кнопками; кнопка → строка той же `loop.command`. go/stop/close/pauseall/closeall — подтверждение (живёт 120 с, кнопки одноразовые); ордер ± — сразу. Только разрешённые чаты |
| Сверка позиции | `loop.position_gaps` | Переданная оператору сторона сверяется, если ею владеет другая живая сетка (SB): нехватка → блок входов SB; ручной шорт сверху — избыток, не блок |
| Проверочный скрипт | `account_now.py` | Ордера (по префиксу) и сделки (по реестру учёта/журнала) сетки, которая сама ведёт переданную сторону, — не нарушение передачи; любая другая сетка там — ПРОБЛЕМА как раньше. Строка объёма стороны: «в т.ч. лоты сеток» |
| Уровни TradingView | `tv_levels.py` | Только сетки с LONG (SB/SE не смешиваются со средней лонгов) |

`pnl_reconcile` не менялся: сделки другой сетки на переданной стороне он и раньше не считал нарушением; SB сверяется
отдельно (`pnl_reconcile.py SB`).
