## TradingView (ТЗ §5–6)
Доступа к аккаунту оператора у Claude нет (вход с паролем — только оператор). Матрица available / approximate /
unavailable / permission_pending по фактическому тарифу — **нет данных**. Ограничения из ТЗ (оценочная дельта по
направлению младших свечей, перерисовка footprint, отсутствие официального API выгрузки, Terms §3 display-only) —
приняты как вводные; машинный сбор из TV не проектируется. Для сравнения методов дельты нужен собственный поток с
агрессором — у нас он есть только для WEEX BTC/ETH (`state/weex_book/*_trades.csv`, поле `m`, 10 дней).
