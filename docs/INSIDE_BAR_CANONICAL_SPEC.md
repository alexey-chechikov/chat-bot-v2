# Inside Bar — КАНОНИЧЕСКАЯ спека (Mac, 2026-05-31)

Чтобы движки СОШЛИСЬ. Win: реализуй ровно это, сверь свой трейд-лист с моим
(`docs/STRATEGIES/inside_bar_trades.csv`, 153 сделки). Где разойдётся — там баг.
Код: `tools/_inside_bar_canonical.py`.

## ПРАВИЛА (фиксированы, без вариаций)
- Данные: BTCUSDT, **4h**, ресэмпл из 1m по UTC-границам (00/04/08/12/16/20).
- Комиссия: **0.15% round-trip** (0.075%/сторона, taker). Slippage 0.
- ATR: **Wilder RMA** True Range, период 14, на 4h (= Pine `ta.atr`).
- Inside bar: бар `i-1` внутри `i-2`: `high[i-1]<high[i-2] AND low[i-1]>low[i-2]`.
- Пробой: **МАТЕРИНСКОГО бара (i-2)**, не внутреннего:
  `close[i]>high[i-2]`→LONG, `close[i]<low[i-2]`→SHORT. (формула в твоём первом
  хендоффе пробивала i-1 — это давало +8%/минусы; реальная = i-2.)
- Вход = `close[i]`. Выход: `TP=entry±5*ATR[i]`, `SL=entry∓3*ATR[i]`, ATR
  фиксируется на баре входа.
- Внутри бара: **SL проверяется ДО TP** (консервативно).
- Stop-and-reverse: противоположный сигнал закрывает по `close[i]` и открывает
  новую сторону. **Single entry — НЕТ pyramiding** (у тебя в TV pyramiding +2 =
  1281 сделка; здесь 153).

выше своей медианы — брейкауты работают на воле, дохнут в флэте):
