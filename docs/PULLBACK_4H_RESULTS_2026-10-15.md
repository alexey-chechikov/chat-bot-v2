# Первый откат после нового 4h тренда — результат (15.10.2026)

**Вердикт: нет. Стратегия не квалифицирована, карточки сделки нет.** Портфель ETH+XRP по протоколу `docs/PULLBACK_4H_PROTOCOL_2026-10-15.md` (коммит 17c970b, опубликован до расчётов) — **«Отвергнута (и n < 100)»**: среднее после расходов **-0.278R** на **26** сделках (нужно > 0 и не меньше 100), при ×2 проскальзывании -0.223R, до расходов -0.167R. Случайный вход той же стороны, в то же время суток и ту же волатильность с тем же стопом (C3) не хуже: ранг **0.779** (нужно ≤ 0.05). Оба исполнимых контроля лучше стратегии: прямой вход на 4h-пробое (C1) -0.181R, тот же откат без ADX (C2) -0.134R. На $3 000 портфель за 2 года 5 месяцев: **-53.88 $**, макс. просадка -69.32 $.

- **ETH отдельно:** «Отвергнута (и n < 100)» — -0.224R, n 12.
- **XRP отдельно:** «Отвергнута (и n < 100)» — -0.245R, n 18.
- **BTC отдельно (в решение не входит):** «Отвергнута (и n < 100)» — -0.176R, n 12.

**По-простому.** Правило почти не торгует: из 389 4h-пробоев ETH+XRP за 2 года 5 месяцев вышло 26 сделок (≈1 в месяц). В 29% событий откат не дошёл до EMA20 за свечи №4…16, в 34% после касания цена ушла за минимум отката (максимум для шорта), в 19% не было подтверждения; из 56 подтверждений 27 отсеяны шириной стопа. Оставшиеся сделки в минусе и до комиссий. Свежие 30% периода в плюсе (+0.350R на 6 сделках), первые 70% — -0.466R на 20: шесть сделок ничего не доказывают, а протокол отказывает по всему периоду. Параметры после результата не менялись и меняться не будут — другая геометрия = новый протокол.

## Отклонения от протокола и формализации

Отклонения:

1. Конец данных общий для трёх монет — по самому короткому файлу; последние минуты выгрузок: ETHUSDT 2026-10-14 20:26, XRPUSDT 2026-10-14 22:46, BTCUSDT 2026-10-14 20:13 UTC. Протокол говорит «до последней закрытой минуты выгрузки» — у ETH/XRP отрезано до 2.5 ч хвоста; закрытий 4h в нём нет (последнее учтённое — 20:00 14.10, следующее — 00:00 15.10, его нет ни в одном файле), незавершённых сделок и ожидающих событий на конце — 0 и 0.
2. Протокол не задаёт приоритет статусов; при среднем ≤ 0 и n < 100 пишу «Отвергнута (и n < 100)».
3. Вне пакета, чтобы полный набор проходил: `tests/services/range_hunter/test_signal.py::test_signal_buy_sell_levels_correct` падал от живого `state` (свежие VAL/VAH рядом с ценой теста подменяли симметричные уровни) — тест изолирован подменой `services.manual_levels.get_levels`; код службы не тронут.
4. Все параметры — из протокола; ничего не подбиралось по результатам. Неоднозначности решены до расчёта (записаны в `replay.py`, FORMALIZATIONS) и проверены тестами:

   - EMA20 касания — значение EMA на закрытии самой свечи касания (включая её close), как линия ema(close,20) в TradingView.
   - ATR14(15m) и ATR/DM внутри ADX: TR и DM начинаются со 2-й свечи непрерывного отрезка (нужен предыдущий бар), seed = среднее первых 14, далее RMA 1/14; индикаторы пересчитываются заново после дыры в данных.
   - Дыра (неполная 15m/4h свеча) в окне 31+1 4h-свечей, в свечах №1…подтверждения или пропущенная минута входа — событие отменяется; пропущенная минута внутри позиции до выхода — сделка цензурирована (в статистику не входит).
   - Отмена по low < low_p проверяется и на самой свече подтверждения: если её low ниже low_p — отмена, даже при закрытии выше двух high (SHORT зеркально). Закрытие за экстремумом 4h-свечи пробоя проверяется первым.
   - Касание на свече №16 — подтверждения быть не может, отмена (истёк срок).
   - Дрейф |open − close подтверждения| ≤ 0.1A считается по сырой цене open; E = open × (1 ± slip); ширина стопа и цель 2R — от E с проскальзыванием (как в §6: E уже содержит проскальзывание).
   - Цель — лимит по цене TP (в т.ч. при гэпе open за цель); стоп — по S × (1 ∓ slip), гэп через стоп — open × (1 ∓ slip); 8 ч — рыночный выход по open минуты entry+480 мин × (1 ∓ slip).
   - Фандинг: начисление считается, если entry < fundingTime ≤ exit, fundingTime округлён вниз до минуты; выход внутри минуты датируется её концом (−1 мс). Вход ровно в минуту начисления — без начисления; выход по open этой минуты — с ним.
   - R = net PnL / (q × (|E − S*| + fee_in×E + fee_out×S*)) — риск позиции после округления q; стоп без гэпа ≈ −1R. Gross R — тот же знаменатель, PnL по сырым ценам (open входа, уровень стопа/цели, open выхода) без комиссий, проскальзывания и фандинга.
   - Дневной лимит: сумма net PnL сделок, закрытых с 00:00 UTC до момента входа, ≤ −0.75% equity на 00:00 UTC → входов до конца суток нет (реализованный, не плавающий).
   - Портфель ETH+XRP: обе машины сигналов работают независимо; вход получает первый по времени входа; при одновременном входе — более раннее 4h-событие, затем ETH раньше XRP. Пока открыта позиция (на любом символе), новые 4h-события обоих символов игнорируются; уже ждущее событие другого символа может войти после выхода, если успеет до свечи №16.
   - Порядок в момент t: свеча 15m, закрывшаяся в t → 4h-событие, закрывшееся в t → входы по open минуты t.
   - Общий конец данных для всех символов — последняя закрытая минута самого короткого файла (+1 мин); сделки, не закрывшиеся до него, — цензурированы.
   - Разрез 70/30 — по календарю периода [2024-05-15; конец), сделка относится к части по времени входа.
   - Бутстрап по ISO-неделям: все календарные недели периода (пустые тоже), 9 999 повторов, seed 20261015, ДИ 95% перцентильный, среднее R = сумма R / число сделок в выборке недель.
   - C3: терциль волатильности = ATR14(15m)/close последней закрытой 15m перед входом, пороги — по всему периоду символа; корзина — час входа UTC // 6; кандидат — вход по open первой минуты 15m-свечи, у которой есть все 481 минута окна; размер — B той же сделки; R и издержки — тем же simulate(). Ранг = (k+1)/(999+1), k — число повторов со средним ≥ среднего стратегии.
   - C1: A = ATR14 последней закрытой 15m (кончается на закрытии 4h-пробоя); вход open первой минуты после пробоя; дрейф не проверяется (подтверждения нет).
