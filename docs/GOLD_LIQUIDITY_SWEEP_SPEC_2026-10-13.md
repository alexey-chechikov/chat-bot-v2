# ТЗ: проверка стратегии золота — ложный пробой, VWAP, footprint и LVN

Проверь на данных идею из видео: https://www.youtube.com/watch?v=kGknlMG5mU8. Расшифровку передам вместе с этим заданием.

**Цель:** выяснить, есть ли положительное матожидание у торговли золотом после неудачного пробоя минимума и дают ли VWAP, footprint и Low Volume Nodes дополнительное преимущество. Показываемая автором прибыль $11 000 доказательством не считается.

Работай в `research/` и `docs/`, без изменения живых ботов, настроек и ордеров.

**1. Сначала зафиксируй данные и протокол проверки**

Укажи инструмент, биржу/брокера, источник, период, часовой пояс, пропуски, комиссии и способ моделирования исполнения.

Для полноценной проверки footprint нужны реальные сделки с объёмом и достоверной классификацией bid/ask. Установи, чем пользуется автор: фьючерсом GC или другим инструментом.

Если таких данных нет:

- Проверь ценовую часть стратегии отдельно.
- Отметь footprint как непроверенный.
- Не восстанавливай «поглощение» из OHLC, цвета свечи или тикового объёма.
- PAXG, XAUUSDT и брокерский XAUUSD рассматривай как отдельные инструменты. Их результаты не выдавай за проверку GC.

До расчёта результатов сохрани механические правила и параметры. Все отклонения от видео обозначь как нашу формализацию.

**2. Основной сетап для проверки на 15 минутах**

Сначала только LONG — направление разобранной автором сделки.

- **Уровень:** минимум предыдущего завершённого UTC-дня с торговыми данными. Правило обработки выходных и неполных дней зафиксировать заранее.
- **Сигнальная свеча:** минимум ниже уровня, закрытие обратно выше него.
- **Подтверждение:** в течение следующих трёх свечей появляется закрытие выше максимума сигнальной свечи.
- **Вход:** на открытии следующей свечи после подтверждения, по доступной цене исполнения.
- **Отмена:** до входа цена обновляет минимум сигнальной свечи либо подтверждение не появилось за три свечи. Отмена имеет приоритет.
- **Стоп:** минимум сигнальной свечи минус два минимальных тика.
- **Цель:** 2 расстояния от фактического входа до стопа.
- **Время позиции:** максимум четыре часа, затем рыночный выход.
- **Ограничения:** одна позиция одновременно; без усреднения; один вход на один сигнал.
- **Размер:** риск 0.25% текущего капитала с учётом комиссии и запаса проскальзывания до стопа. Округлять вниз по спецификации инструмента. Если минимальный контракт превышает риск — пропускать сделку.
- **Дневной лимит:** после потери 0.75% капитала новые входы до следующего дня запрещены; открытая позиция продолжает сопровождаться.

При гэпе через стоп учитывать фактическую доступную цену. Не ограничивать убыток искусственно ровно одним риском.

**3. Проверить добавочную пользу каждого элемента**

Посчитать отдельно:

| Версия | Правила |
|---|---|
| A | Основной ценовой сетап |
| B | A + подтверждающее закрытие выше дневного VWAP |
| C | B + footprint-подтверждение |
| D | C + заранее известный LVN |
| E | B + LVN, если footprint-данных нет |

VWAP считать с начала UTC-дня только по доступным на тот момент данным. При приближённом расчёте из минутных свечей указать приближение.

Для footprint заранее формализовать «много продаж, но цена не продолжает падать». Первый фиксированный вариант: отрицательная дельта в нижнем фитиле сигнальной свечи ниже 10-го перцентиля аналогичного показателя за предыдущие 20 завершённых торговых дней. Объяснить алгоритм классификации сделок и обработки пустого фитиля.

Для LVN до просмотра результатов зафиксировать алгоритм выделения зоны, ширину ценовых корзин и допустимое расстояние сигнала от зоны. Основное окно — два предыдущих завершённых торговых дня. Окна **1/70/246 дней** проверять отдельно как чувствительность, не выбирать победителя по итоговой прибыли.

Профили строить исключительно из прошлого. Для фьючерсов объяснить обработку смены контрактов: склейка не должна создавать искусственные уровни или использовать будущие поправки.

**4. Контроль исполнения и расходов**

- Использовать bid/ask и реальные комиссии выбранного инструмента, где они доступны.
- Отдельно показать результат до расходов, после расходов и при удвоенном проскальзывании.
- Если стоп и тейк попали в одну свечу, разрешить порядок по более мелким данным. При их отсутствии считать неблагоприятный исход и показать количество таких сделок.
- Не давать лимитной заявке гарантированное исполнение от одного касания.
- Не применять эффективную комиссию WEEX 1 bp автоматически к другому рынку.

**5. Проверка преимущества**

Разделить историю хронологически. Первую часть использовать для разработки, последние 30% оставить нетронутыми до фиксации правил. Если нужны изменения — окончательную часть не превращать в повторную обучающую выборку.

Обязательные сравнения:

- A против B: добавляет ли VWAP пользу.
- B против C: добавляет ли footprint пользу.
- C против D или B против E: добавляет ли LVN пользу.
- LVN против обычных уровней на сопоставимом расстоянии от цены.
- Footprint против случайного отбора такого же количества базовых сигналов, сопоставленного по времени суток и волатильности.

Доверительные интервалы считать с группировкой по дням или неделям, сохраняя зависимость сделок. Малое количество сделок обозначать как недостаток доказательств.

**6. Что должно быть в отчёте**

Для каждой версии:

- Количество сделок, оборот, win-rate.
- Средний выигрыш, проигрыш и **ожидание на сделку в R и долларах**.
- Комиссии, проскальзывание, profit factor.
- Максимальная просадка и серия убытков.
- Результаты по годам/кварталам и на окончательной выборке.
- Доверительный интервал ожидания.
- Сколько сделок пропущено из-за минимального размера контракта.
- Несколько прибыльных и убыточных примеров с уровнями, известными **до входа**.

Посчитай денежную реализуемость для капитала **$1 000, $3 000 и $5 000**. Короткий стоп и красивое отношение цели к стопу сами по себе преимуществом не считать.

**7. Итог и публикация**

По каждой версии вынеси один статус:

**«Отвергнута» / «Недостаточно данных» / «Кандидат на малый тест исполнения».**

Если кандидат есть, укажи конкретные условия, при которых преимущество исчезает: расходы, проскальзывание, режим рынка, размер позиции.
