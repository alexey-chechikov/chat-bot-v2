## 3. Новый живой код (`services/weex_grid/engine.py`, 250 строк)

- `regime_up()` (стр. 161): дневки Binance spot, закрытые дни (`close_time < now`), закрытие последнего закрытого
  дня > SMA100 закрытых дней → True. Кэш 30 мин; сбой — прежнее решение до суток, дальше None.
- `tick()` (стр. 685–715): `release_sides` — передача стороны; `regime_sma > 0` — разрешённые стороны по режиму,
  сторона не по режиму с лотами/входом → `_flatten_side`; режим None → новых входов нет, ничего не закрывается.
  Стороны в передаче/закрытии не сопровождаются обычным `_side` (иначе тейки встали бы снова).
- `release_side()` (стр. 986): pending → resolve; снять вход (`_drop_entry`); каждый тейк — cancel → `order_info` →
  `_take_tp_fill(terminal)`; не конечный статус → False (повтор); strays → `_process_strays`; затем журнал
  «передано оператору» и лоты из учёта убираются.
- `_flatten_side()` (стр. 1029): (1) pending → resolve; (2) снять вход и тейки как выше; (3) намерение
  `s["flatten"]={cid,qty,t,srv}` на диск ДО POST; один `place_market(reduceOnly)` на объём лотов бота;
  (4) потерянный ответ → `_find_by_cid` (неполный поиск не доказывает отсутствие, до TTL не повторяем);
  (5) исполнение по курсору `filled/filled_val`, распределение по лотам FIFO, комиссия через `fee_book`;
  частичное — остаток следующим ордером; (6) отказ → `_reconcile_side` (учёт к позиции биржи), 3 отказа подряд →
  halt + сообщение.
- `DryExchange.place_market` (стр. 1240): reduceOnly не больше позиции стороны, нет позиции — отказ.
- Тесты: `tests/services/weex_grid/test_weex_regime.py` (5: смена режима → один рыночный, вход заблокирован, вход
  после возврата; потерянный ответ без второго ордера; частичное; ручное закрытие половины + смена режима без
  бесконечных повторов; режим неизвестен), `test_weex_release.py` (передача стороны с частично исполненным
  тейком). Всего 729 тестов проекта проходят.

**Твои R1–R7 из `WEEX_GPT_STATE_RECHECK` НЕ исправлены.** Для живых сеток прямо касается R5 (усыновлённая сирота не
уменьшает место под общим потолком); R1–R4, R6, R7 — тренд (он холостой). Режимный выход не использует
стоп-ордер на бирже: если мак лежит в момент смены режима, лонги висят до подъёма бота.
