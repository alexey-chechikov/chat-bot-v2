## Почему так
- **Расходы больше любого возможного края.** Медиана стопа 0.30% цены; круг расходов PAXG (0.10% + 0.10% +
  проскальзывание) 0.24% ≈ 0.79R. Чтобы расходы были ≤ 0.2R (ворота 1 CLAUDE.md), нужен стоп ≥ 1.2%. Даже цель 2R
  после расходов даёт в среднем +0.57R, средний проигрыш −0.76R.
- **Цель почти не достигается:** из 312 сделок A — 24 по цели, 147 по стопу, 141 по времени (4 ч). WR 21%.
- **VWAP (A↔B):** чистый ценовой R без влияния размера: A −0.070R, B −0.005R (контрольная часть B −0.102R) —
  разница в пределах шума, после расходов B всё равно −0.45R.
- **LVN против обычных уровней (999 случайных размещений):** PAXG ранг 0.258, XAU 0.845 — LVN не лучше случайных
  корзин. Окна 1/70/246 дней: PAXG 8/7/6 сделок (−0.60/−0.16/−0.24R), XAU 3/2/0 — данных мало, все в минусе.
- **Footprint (B↔C):** нужны сделки с флагом агрессора (aggTrades). Для PAXG за 2.4 г. это десятки миллионов сделок,
  для XAU — тяжёлый по весу запрос; архивы data.binance.vision — скачивание файлов, нужно разрешение оператора.
  Не проверено. Ограничение сверху: C — подмножество B, у которого ценовой R ≈ 0; чтобы стать кандидатом, отобранные
  footprint-ом сделки должны дать > +0.45R до расходов на PAXG.
- **Инструмент автора** (GC / MGC / XAUUSD) не установлен: расшифровка к заданию не приложена, со страницы видео
  доступен только заголовок. Результаты PAXG/XAUUSDT за проверку GC не выдаются.
- Похожее уже опровергалось на крипте (CLAUDE.md, `project_direction_refuted`): пробои уровней M1/H1, свипы
  ликвидаций, «удобные уровни» TradingView.
