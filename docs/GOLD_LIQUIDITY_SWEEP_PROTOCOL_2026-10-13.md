## 1. Инструмент автора

к заданию не приложена. Чем торгует автор (GC, MGC, брокерский XAUUSD) — **не установлено**. Поэтому ниже —
проверка ценовой части на криптовалютных инструментах золота; это НЕ проверка GC и за неё не выдаётся.

## 3. Основной сетап (версия A) — только LONG
- **Уровень L(d):** минимум всех 1m предыдущего завершённого UTC-дня, в котором были сделки. I1 торгуется каждый
  день — выходные входят **[формализация]**; чувствительность S1: сигналы только пн–пт, уровень — минимум
  предыдущего буднего дня. I2: день без торгов пропускается, уровень — последний день с данными; день с данными
  менее чем за 12 ч считается неполным и уровнем не служит (берётся предыдущий полный) **[формализация]**.
- **Сигнальная свеча (15m):** low < L и close > L.
- **Подтверждение:** первая из следующих трёх свечей с close > high сигнальной.
- **Отмена (приоритет):** если у любой свечи от первой после сигнальной до подтверждающей включительно low <
  low сигнальной — отмена; нет подтверждения за три свечи — отмена.
- **Вход:** open свечи, следующей за подтверждающей, рыночный: цена × (1 + проскальзывание), комиссия тейкера.
- **Стоп:** low сигнальной − 2 тика; срабатывает, когда 1m low ≤ стопа; исполнение по min(стоп, open этой минуты)
  × (1 − проскальзывание) — гэп через стоп не ограничивается одним риском; комиссия тейкера.
- **Цель:** вход_факт + 2 × (вход_факт − стоп); лимитная продажа, исполнение только если 1m high ≥ цель + 1 тик
  (касание не исполняет); по цене цели, комиссия мейкера, без проскальзывания.
- **Стоп и цель в одной 1m-свече** → считается стоп (неблагоприятно), такие сделки считаются отдельно.
- **Время:** не дольше 4 ч; выход по open первой минуты в момент вход+4ч или позже, рыночный.
- **Ограничения:** одна позиция; без усреднения; один вход на сигнал; пока сигнал ждёт подтверждения или открыта
  позиция, новые сигналы не берутся **[формализация]**; несколько сигналов за день разрешены.
- **Размер:** R$ = 0.25% текущего капитала (сложный процент). Риск на единицу = (вход − стоп) + комиссия входа +
  комиссия и проскальзывание на стопе. qty = округление вниз (R$ / риск на единицу) по шагу. Номинал больше
  разрешённого (I1 — капитал, I2 — 20× капитал) → qty урезается (такие сделки считаются). qty < minQty или
  номинал < 5 USDT → сделка пропускается (считается).
- **Дневной лимит:** реализованный убыток UTC-дня ≥ 0.75% капитала на начало дня → новых входов до следующего дня
  нет; открытая позиция сопровождается.
- Капитал $1 000 / $3 000 / $5 000, каждый отдельно; итог в R = PnL / R$ сделки.

## 4. Версии
| | Правило |
|---|---|
| A | сетап п.3 |
| B | A + close подтверждающей свечи > дневной VWAP на момент её закрытия. VWAP с 00:00 UTC по 1m: Σ(typ×vol)/Σvol, typ = (h+l+c)/3 — **приближение** к VWAP по сделкам |
| C | B + footprint (см. ниже) |
| D | C + LVN |
| E | B + LVN (если footprint не проверен) |

**Footprint [формализация по ТЗ].** Дельта нижнего фитиля сигнальной свечи = объём сделок покупателя-агрессора −
продавца-агрессора по сделкам с ценой ≤ min(open, close) сигнальной свечи. Классификация — флаг биржи
`isBuyerMaker` в aggTrades Binance (true → агрессор продавец). Условие C: дельта фитиля < 10-го перцентиля того же
показателя по всем 15m-свечам предыдущих 20 завершённых торговых дней. Пустой фитиль (min(open, close) = low,
сделок в фитиле нет) — условие не выполнено. Если сделки по инструменту за период не получены — C и D помечаются
«не проверено», и считается E. «Поглощение» из OHLC, цвета свечи или тикового объёма НЕ восстанавливается.

**LVN [формализация].** Профиль объёма предыдущих 2 завершённых торговых дней из 1m: объём минуты делится поровну
между ценовыми корзинами её диапазона [low, high] (**приближение** к профилю по сделкам). Корзина — 0.05% цены
закрытия предыдущего дня. Зона стоимости — корзины между 5-м и 95-м перцентилями объёма по цене. LVN-корзина —
корзина зоны стоимости с объёмом < 25% медианной корзины зоны; LVN-зона — непрерывный ряд таких корзин. Сигнал
«у LVN», если уровень L лежит внутри зоны или не дальше 0.15% цены от её края. Чувствительность — окна 1, 70 и
246 дней (те же параметры), победитель по прибыли не выбирается.

## 5. Проверка преимущества
- Хронологический разрез: первые 70% календарного периода каждого инструмента — разработка, последние 30% —
  контрольная часть. Правила зафиксированы этим файлом до прогона; подбора нет, поэтому показываются обе части,
  решение — по контрольной части и по всему периоду.
- Сравнения: A↔B (VWAP); B↔C (footprint); C↔D или B↔E (LVN).
- **LVN против обычных уровней:** вместо LVN-зон — столько же случайных корзин зоны стоимости той же ширины, не
  LVN; то же правило расстояния; 999 повторов; ранг (k+1)/(n+1) ожидания в R.
- **Footprint против случайного отбора:** из сигналов B — случайные подвыборки того же размера, что C, с тем же
  составом по времени суток (корзины по 6 ч UTC) и терцилям волатильности (диапазон предыдущего дня / цена);
  999 повторов; ранг.
- Доверительный интервал ожидания в R: бутстрап блоками по ISO-неделям, 9 999 повторов, 95%.
- Ворота CLAUDE.md: издержки круга в R по медиане стопа (порог: издержки ≤ 0.2R не выполняются автоматически —
  показываются), n ≥ 100 для вывода.

## 6. Статусы (заданы заранее)
- **Кандидат на малый тест исполнения:** ожидание после расходов > 0 и на всём периоде, и на контрольной части;
  нижняя граница 95% ДИ всего периода > 0; n ≥ 100; > 0 при удвоенном проскальзывании.
- **Недостаточно данных:** n < 100, либо оценка > 0, но ДИ включает 0.
- **Отвергнута:** ожидание после расходов ≤ 0 на всём периоде или на контрольной части.

## 7. Реализуемость
Для $1 000 / $3 000 / $5 000: сколько сделок пропущено из-за минимального размера, сколько урезано по номиналу;
отдельно — сколько сигналов было бы исполнимо микро-фьючерсом MGC (10 унций, тик $0.10 = $1) при риске 0.25%:
риск одного контракта = (вход − стоп) × 10 + расходы ≤ R$.
