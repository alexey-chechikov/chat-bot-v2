## 2. Что появилось для CoinGlass

В [папке ежедневного контекста](../research/coinglass_daily_context_20261016/) опубликованы три helper и три самостоятельных набора синтетических тестов:

- [archive_daily.py](../research/coinglass_daily_context_20261016/archive_daily.py): локальное неизменяемое архивирование, evidence SHA, null вместо ложных нулей, защита от backdating и выхода пути.
- [fetch_public_context.py](../research/coinglass_daily_context_20261016/fetch_public_context.py): один конечный публичный Binance BTCUSDT проход, максимум шесть GET без повторов, закрытые 15m свечи и отдельные OI/funding.
- [analytics_daily.py](../research/coinglass_daily_context_20261016/analytics_daily.py): полностью offline, сопоставимость определений, взвешенный F, согласованные окна, будущие 15/60/240/1440m исходы и PENDING/MISSING.

Синтетические тесты запускаются из корня чистого checkout: `python -B -m unittest discover -s research/coinglass_daily_context_20261016 -p "test_*.py" -v`. Сетевой helper при аудите не запускать. Тесты создают выдуманные фикстуры; реальные CoinGlass архивы для code review не нужны. Требование IANA tzdata указано в README.

Сохранённые проверки: 21 archive + 25 fetch + 24 analytics = 70 тестов по отдельным прогонам. В общем прогоне был один временный Windows rename AccessDenied; целевой повтор прошёл. Это не один безошибочный общий прогон. При публикации тесты заново не запускались; все 15 пинов [VERIFIED_FILES.json](../research/coinglass_daily_context_20261016/VERIFIED_FILES.json) сверены с текущими файлами.

На 18 октября фактически сохранены два реальных ежедневных пакета: 16-е и 18-е. За 17-е пакета нет; причина пропуска не установлена, задним числом он не создан. Сегодняшний сбор занял 86 секунд: четыре браузерные страницы, шесть публичных REST GET, 96 закрытых свечей каждого рынка и 97 OI-точек без пропусков текущего окна, 20 проверенных evidence SHA. Повтор offline-аналитики возвращает существующий анализ без изменения его SHA.

Все восемь исходов первой аналитической записи (два рынка × 15/60/240/1440m) остались MISSING: для коротких горизонтов нет баров, для суток есть лишь 19 из 96. **Нет права объявлять первую интерпретацию подтверждённой или опровергнутой.** Человеческая заметка имеет собственное фактическое время; её anchor не раньше ceil(max(note-created, analysis-created)/15m). Суточная частота и пропуски запуска не гарантируют покрытие коротких горизонтов.

Старый ручной пилот: один завершённый вторичный эпизод, 300 минут без пропусков. Основная шестичасовая серия N=0. Пилот не смешивается с ежедневным контекстом и не превращается в две прибыльные сделки.

Сырые JPEG/DOM, реальные daily JSON/отчёты/заметки и journal.sqlite **остаются локальными и в эту публикацию не входят**. В репозитории находятся код, синтетический пример, методика и обезличенный статус покрытия. Задержка публикации CoinGlass и числовые матрицы карт остаются неизвестными/недоступными.
