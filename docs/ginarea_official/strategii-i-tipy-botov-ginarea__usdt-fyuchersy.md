# USDT-фьючерсы

<figure><img src="https://350783642-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FtOJARNyb8xHRAoEXMfKw%2Fuploads%2FbaMFfgxmzm6sF0B41reW%2Fimage.png?alt=media&amp;token=4741d6ed-7fe3-4f89-bb95-8a407aea8e20" alt=""><figcaption></figcaption></figure>

**USDT-фьючерсы** предназначен для торговли фьючерсными контрактами, номинированными в USDT.

#### Доступные стратегии для USDT-фьючерсы <a href="#dostupnye-strategii-dlya-usdt-futures-bot" id="dostupnye-strategii-dlya-usdt-futures-bot"></a>

* [**Default**](/ginarea.org/strategii-i-tipy-botov-ginarea/default-grid.md) — стандартная стратегия с фиксированными параметрами сетки ордеров. Подходит для стабильных рыночных условий.
* [**Auto Grid**](/ginarea.org/strategii-i-tipy-botov-ginarea/auto-grid.md) — автоматическая настройка сетки ордеров в зависимости от текущих рыночных условий. Эта стратегия позволяет боту адаптироваться к изменчивой волатильности рынка.
* [**Dynamic**](/ginarea.org/strategii-i-tipy-botov-ginarea/dynamic-grid.md) — динамическая стратегия, которая постоянно адаптируется к волатильности рынка, передвигая границы, определяющие направление открываемых ордеров в реальном времени для максимизации прибыли.
* [**Indicator Grid**](/ginarea.org/strategii-i-tipy-botov-ginarea/indicator-grid.md) — это специализированный тип ботов, предназначенный для трейдеров, активно использующих торговые стратегии, основанные на индикаторах EMA, RSI, MA, SMMA, ATR, ATR% и Supertrend.
