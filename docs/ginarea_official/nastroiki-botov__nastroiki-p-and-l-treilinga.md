# Настройки P\&L трейлинга

<figure><img src="https://350783642-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FtOJARNyb8xHRAoEXMfKw%2Fuploads%2FmFQI0no3DcpHQhhLrRhp%2Fimage.png?alt=media&amp;token=7b7bb63a-53a8-4f6d-9aaf-f2cc4e5c58b3" alt=""><figcaption></figcaption></figure>

**P\&L трейлинг** — это функционал, который позволяет подтягивать среднюю точку входа, закрывая дальние убыточные триггеры.

**Стартовая дистанция** — это начальное расстояние, которое определяет на каком уровне будет активирован трейлинг P\&L. Трейлинг активируется, когда цена преодолевае расстояние равное  **стартовая дистанции** от самого дальнего триггера.

**% на трейлинг** — это процент прибыли, который будет отдаваться с каждого закрытого ордера для накопления и подтягивания триггеров. Этот параметр позволяет ботам эффективно управлять рисками и фиксировать прибыль.

Когда накопленный профит достигает достаточного уровня, он может быть использован для закрытия самых дальних убыточных триггеров в минус. В этом случае убыточный триггер будет закрыт, а накопленный профит будет списан.

[Видео P\&L Трейлинга](https://youtu.be/eJqOarb5P18?si=qZ2m_CPycxrx3ko7)

***

Количество накопленного профита, предназначенного для списания, можно отслеживать в сводной статистике в графе "**Профит на трейлинг**".

Трейлинг P\&L начинает работать сразу после активации функции. Если на момент включения цена уже отклонилась от дальнего триггера больше, чем на значение **«Стартовая дистанция»**, бот начнёт накапливать профит с момента активации функции. Если функция включена заранее (изначально), бот начнёт накапливать профит, как только цена отклонится от дальнего триггера на значение **«Стартовая дистанция»**.
