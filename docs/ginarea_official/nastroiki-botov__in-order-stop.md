# In Order stop

<figure><img src="https://350783642-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FtOJARNyb8xHRAoEXMfKw%2Fuploads%2FVNj1WsEtY8BnD4rBastA%2Fimage.png?alt=media&amp;token=2b8b9cf3-eb81-49fc-a106-ab1f54129336" alt=""><figcaption></figcaption></figure>

**IN Order Stop** — это параметр, который позволяет трейдеру контролировать момент открытия IN-ордеров, основываясь на отклонении цены.

[Видео In Order Stop](https://youtu.be/Mu_JJ_OWdZ0?si=eoRxLsfFMHE5yAdf)

***

**Принцип работы:**

* Если **IN Order Stop** больше 0, бот будет открывать IN-ордера только после того, как текущее отклонение цены превысит установленное значение **IN Order Stop**.
* В случае изменения направления цены (например, в сторону убытка), все активные IN-ордера объединяются в один общий ордер с единым триггером, что улучшает эффективность работы бота.

***

**Пример работы (на примере Long-бота):**

1. **При росте цены:**
   * Бот создает IN-ордера на расстоянии **Grid Step** и для каждого из них он отслеживает отклонение цены на значение **IN Order Stop**.
   * Если цена продолжает расти, бот будет продолжать выставлять IN-ордера, но первый ордер будет создан только после отклонения цены на величину **IN Order Stop**.
   * Шаг сетки (Grid Step) не изменится и все последующие ордера будут открываться в соответствии с параметрами сетки, как обычно.
2. **При падении цены:**
   * Бот не откроет первый ордер сразу при падении цены. Он дождется, пока снижение цены прекратится и цена развернется.
   * IN-ордер будет открыт только когда цена вырастет на величину, равную значению **IN Order Stop**, после разворота от минимальной цены.
3. **При безоткатном движении цены вниз:**
   * Если цена падает без откатов и проходит несколько уровней **Grid Step**, бот не будет открывать каждый отдельный IN-ордер на каждом уровне сетки.
   * Вместо этого, при развороте цены вверх на величину **IN Order Stop**, бот откроет один общий ордер, который будет равен сумме всех пропущенных IN-ордеров, и выставит его с общим триггером на дистанции **Target Distance**.

***

**Преимущества:**

* **IN Order Stop** позволяет боту улучшать позицию, открывая ордера только после изменения направления движения цены, что помогает захватить более выгодные точки входа.
* Это особенно полезно в условиях резких движений на рынке, когда необходимо подождать разворота перед открытием нового ордера.
* За счет трейлинга открытия ордеров можно увеличить потенциальную прибыль, торгуя с более точной синхронизацией с рынком.

***

**Важно:**

* **IN Order Stop** откладывает открытие первого ордера до того момента, когда цена изменится на величину, заданную в параметре **IN Order Stop**.
* Параметр **IN Order Stop** доступен только для ботов [**DEFAULT**](/ginarea.org/strategii-i-tipy-botov-ginarea/default-grid.md) и [**DYNAMIC**](/ginarea.org/strategii-i-tipy-botov-ginarea/dynamic-grid.md) стратегиями.

***

Использование **IN Order Stop** дает возможность более гибко реагировать на изменения рынка, избегая открытия ордеров в неблагоприятных точках и улучшая позиции при сильных движениях цены.
