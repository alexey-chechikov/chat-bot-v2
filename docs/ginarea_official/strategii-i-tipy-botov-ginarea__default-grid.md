# Default grid

<figure><img src="https://350783642-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FtOJARNyb8xHRAoEXMfKw%2Fuploads%2FKORWIR32JRusX3GlTOax%2Fimage.png?alt=media&amp;token=b1ce862d-2a4a-4dcc-a989-82b0d29eb025" alt=""><figcaption></figcaption></figure>

**Default** — это классическая стратегия, предназначенная для работы в одном направлении. Бот подходит как для лонговых (Long), так и для шортовых (Short) позиций, предоставляя простоту настройки и надежность для трейдеров, предпочитающих более консервативный подход.

***

* **Spot Bot**
* **USDT Futures Bot**
* **Coin Futures Bot**
