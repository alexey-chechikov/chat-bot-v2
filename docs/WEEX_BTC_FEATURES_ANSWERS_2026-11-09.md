## 1. Система (что проверяется)
`services/btc_signals/engine.py` (докстринг — точные правила; копия индикатора `docs/tv_pine_scripts/bot7_operator_strategy_A.pine`,
сверка с Python 536/536 сделок): Binance BTCUSDT, по часам, линии 4ч (TEMA50/100/200, EMA200 — «синяя») по последней
закрытой свече 4ч. Лонг над синей: 2 закрытия 4ч над зелёной, выход 2 под красной. Шорт под синей: 2 под зелёной, ранг
ATR100 ≤ 0.6, выход 2 над зелёной. Шорт под жёлтой (над синей, второе закрытие под жёлтой): цель синяя +0.5%, отмена 2 над
жёлтой. Добор 0.5+0.5 при ходе 2 ATR. Вес = медиана V / V (0.5–2) / 1.18. Учёт: % от $1000 с весом, 0.068%/сторону.

База (с фандингом, `plus.stats`): итог +556 / просадка −34; 2018–22 +358, 2023–26 +198, с 2025 +35; Bitstamp 2014–17 +401 / −64.
432 (`engine.simulate432`, пробой 30 свечей 4ч, ADX ≥ 22, выше EMA200, выход — минимум 30 или 20 свечей): 116 сделок
+326 без фандинга; сверка с `research/chart_walk_20261105/btc_vs_432.py` — 116/116, выходы в тот же час. Вместе с
системой независимо: +863 / −52 (с 2025 +66 против +35) — `combo_432.py`.

## 7. Мои слабые места (проверьте их в первую очередь)
1. Множественные проверки: к каждому PREREG есть «дописано после» — вторые попытки (M2, базис, дивергенция, условный
   выход, макро). Перестановки считают шум внутри одного прогона, но не между прогонами.
2. Мало сделок: шорт под жёлтой 40/45/56, 432 на проверке 50, поздние признаки 26–92 на половину.
3. Пропуски заполняются медианой (связки, модель); у поздних признаков нулевое распределение считается по каждому
   признаку отдельно (зависимость между признаками не сохранена).
4. «Итог» в таблице — без фандинга (engine.res); с фандингом проверен только базис.
5. Моменты «известно»: CoinMetrics/стейблкоины — день + 2 суток; metrics Binance — ts + 4ч (не знаю, начало или конец
   окна у агрегата Вина); DVOL — час + 1ч; макро — дата + 1 сутки. Золото — ближний фьючерс GC=F (переходы контрактов).
6. Группы дублей — одиночной связью (цепочка может склеить слабо связанные признаки).
7. Механика: связи признаков с отдачей/MFE во многом заданы правилами выхода (расстояние до красной ↔ отдача лонга).
8. Данные Вина (спот 1ч с агрессором, metrics, CoinMetrics, DVOL, стейблкоины) кончаются 06.11 — живого сборщика нет.
