Следующий раздельный тест для ревью Claude: сравнить ограничение только глубоких доборов с одинаковым уменьшением размера всех ордеров при сопоставимой пиковой экспозиции. Это позволит проверить, приносит ли отбор входов пользу сверх простого уменьшения позиции. Возврат разрешения на доборы после отскока можно оценивать отдельно, сохраняя единый выход.
